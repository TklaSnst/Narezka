# ShortsCutter

Десктопное приложение для Linux: длинное видео с YouTube → набор вертикальных шортсов (9:16).
Нарезка по смыслу (локальные Whisper + LLM), настраиваемый внешний вид по шаблонам,
баннеры и рекламные вставки (Lumen VPN), пакетный рендер.

Общение с пользователем — на русском.

## Как работать в этом репозитории

Работа разбита на этапы, между которыми контекст сессии очищается. Вся память проекта — в `docs/`.

**В начале каждой сессии:**
1. Прочитай `docs/STATUS.md` — там текущий этап и следующий шаг.
2. Прочитай файл текущего этапа в `docs/phases/`.
3. Остальные документы читай по ссылкам из файла этапа, а не все подряд.

**В конце крупного куска работы (до очистки контекста):**
1. Отметь выполненные задачи `[x]` в файле этапа.
2. Заполни раздел «Передача дальше» в файле этапа: что сделано, что не получилось, неочевидные находки.
3. Обнови `docs/STATUS.md`: текущий этап, следующий конкретный шаг, блокеры.
4. Новые архитектурные решения — в `docs/DECISIONS.md` (кратко: решение, причина, дата).
5. Сделай git-коммит.

## Документы

| Файл | Что внутри |
|---|---|
| `docs/STATUS.md` | Где мы сейчас и что делать дальше — **читать первым** |
| `docs/PLAN.md` | Обзор всех этапов, зависимости, MVP |
| `docs/SPEC.md` | Требования пользователя: что должно уметь приложение |
| `docs/ARCHITECTURE.md` | Стек, модули, модель данных, пайплайны анализа и рендера |
| `docs/DECISIONS.md` | Журнал решений |
| `docs/phases/NN-*.md` | Задачи этапа, критерии приёмки, заметки для передачи |
| `docs/references/` | Скриншоты шортсов-референсов и их разбор |

## Окружение пользователя

- Ubuntu + Hyprland (Wayland), но приложение не должно зависеть от дистрибутива.
- GPU: AMD RX 6600 (RDNA2, 8 ГБ). VAAPI: H.264/HEVC encode есть, AV1 encode — нет. ИИ — через Vulkan (без ROCm).
- Всё ИИ — **только локально**, никаких облачных API.

## Соглашения

- Язык: Rust (workspace), GUI: egui/eframe (glow). Детали — `docs/ARCHITECTURE.md`.
- Внешние зависимости рантайма (ffmpeg, libmpv) — системные; возможности ffmpeg проверяются при запуске, а не предполагаются.
- Тексты интерфейса — только через i18n-ключи (RU/EN), без строк в коде.
