# Архитектура

Статус: проектная. Пункты с пометкой **(проверить на этапе 0)** — гипотезы, их подтверждает или меняет этап 0.

## 1. Стек

| Компонент | Выбор | Зачем |
|---|---|---|
| Язык | Rust (Cargo workspace) | Безопасность, хорошие биндинги, `cargo-deb` |
| GUI | egui / eframe, бэкенд **glow** (OpenGL) | Wayland из коробки, холст с drag-and-drop, свои шейдеры через `PaintCallback`, совместимость с mpv render API |
| Превью-плеер | libmpv (render API → OpenGL FBO/текстура) **(проверить)** | VAAPI-декод, точный seek, A/V-синхронизация, проигрывание отрезка |
| Рендер | системный `ffmpeg` (subprocess), граф `filter_complex` генерируется из модели | Надёжно, все кодеки, `-progress` для прогресса |
| Распознавание речи | whisper.cpp через `whisper-rs`, бэкенд Vulkan, модель large-v3-turbo **(проверить)** | Таймкоды слов, русский, работает на AMD без ROCm |
| LLM | llama.cpp (бэкенд Vulkan), модель ~7–9B Q4/Q5 с хорошим русским — выбирается на этапе 0 | Смысловая нарезка, заголовки, ключевые слова |
| Эмбеддинги | локальная мультиязычная модель (класса multilingual-e5) через llama.cpp | Страховочный алгоритм смены темы |
| Растеризация текста/графики | cosmic-text + tiny-skia | Один растеризатор для превью и рендера → совпадение текста |
| Субтитры в рендере | ASS + libass (фильтр `ass` в ffmpeg) | Шрифт, обводка, позиция, караоке (`\k`) |
| i18n | Fluent (`fluent-bundle`) | RU/EN |
| Пути | `directories` (XDG) | Переносимость |
| Уведомления | D-Bus (`notify-rust`) | mako/dunst/swaync на Hyprland |
| Конфиги | serde + TOML (настройки, шаблоны), JSON (кэш анализа) | Читаемо руками |
| Упаковка | `cargo-deb` | |

Способ подключения whisper.cpp/llama.cpp (линковка через биндинги или отдельный бинарник-сервер)
выбирается на этапе 0 по результатам сборки с Vulkan.

## 2. Модули (crates)

```
crates/
  core       — модель данных (шаблоны, пачка, шортсы, ассеты), сериализация, валидация
  media      — ffprobe, извлечение аудио/кадров, проверка возможностей ffmpeg (encoders, hwaccels)
  analysis   — whisper, разметка предложений/пауз, LLM-нарезка, эмбеддинги, кэш
  raster     — отрисовка текстовых слоёв, капсул, обложек в RGBA (cosmic-text + tiny-skia)
  compositor — GPU-композиция превью: фон (blur-шейдер), кропы видео, слои, safe zones
  render     — построение команд ffmpeg, ASS-генератор, очередь задач, прогресс
  library    — библиотека ассетов, история «как в прошлый раз», пресеты
  i18n       — ресурсы Fluent
  app        — egui-приложение (бинарник shortscutter)
```

Правило зависимостей: `core` ни от чего не зависит; `app` зависит от всех; `render` и `compositor`
не зависят друг от друга, но оба читают одну и ту же модель из `core` (источник истины — модель, а не превью).

## 3. Модель данных (описание, не код)

**Template**
- `canvas`: ширина, высота (по умолчанию 1080×1920)
- `background`: один из — `Blur { source: main, darken %, scale }`, `Color`, `Gradient`, `Image(asset)`, `Video(asset, loop)`
- `layers` (упорядоченный список, z-order):
  - `MainVideo { crop_rect (в долях исходника), dest_rect (в долях холста), corner_radius, border, shadow }` — может быть несколько (шаблон «Два экрана»)
  - `Text { content с разметкой акцента *…*, font, size, color, accent_color, accent_mode: Color|Plate, outline, shadow, rect, align }`
    — поддерживает подстановки `{part}`, `{title}`
  - `Image { asset, rect, opacity }`
  - `Capsule { logo asset, text, colors, rect }`
  - `Subtitles { style, rect, mode: Static|WordHighlight|Reveal, words_per_line, colors }`
  - `BannerSlot { rect }` — место под баннер пачки
- все координаты — в долях холста (0..1), чтобы шаблон работал при любом выходном разрешении

**Batch** (пачка)
- `sources[]` (путь, ffprobe-информация, хэш, статус анализа)
- `template` (ссылка + локальные правки)
- `banner: Option<{asset, rect, text_layer?}>`
- `insert_default: Option<asset>`
- `output: { dir, base_name, container, codec, quality preset/advanced, resolution, fps, conflict_policy, export_metadata, notify }`

**Short** (шортс)
- `source_id`, `in`, `out` (секунды, привязаны к границам слов)
- `title`, `score`, `reason`, `status: Candidate|Accepted|Rejected`
- `insert: Option<{asset, at (сек. внутри шортса), hide_banner}>`, флаги `no_banner`, `no_insert`
- `cover: Option<{source: Frame(t)|Image(asset), overlays[], duration_frames}>`
- `subtitle_overrides` (исправленный текст)

**Transcript** (кэш по хэшу файла): слова `{text, start, end, prob}`, предложения, паузы, исключённые зоны.

**Asset** (библиотека): тип (banner/insert/image/font/background), путь (копия в библиотеке), метаданные
(размер, длительность, ориентация, альфа), теги, история использования (дата, позиция, параметры).

## 4. Пайплайн анализа

1. `ffmpeg` → mono 16 кГц WAV во временный каталог.
2. Whisper (Vulkan) → слова с таймкодами. Словарь терминов из настроек передаётся как initial prompt.
   Модель выгружается из VRAM после работы (Whisper и LLM не держим одновременно — 8 ГБ).
3. Разбиение на предложения, паузы между словами (паузы — по таймкодам слов; `silencedetect` только как доп. сигнал,
   т.к. под голосом может быть музыка).
4. LLM, проход 1 — **границы тем**: окна ~5–8 мин с перехлёстом, на входе пронумерованные предложения
   с таймкодами, выход — JSON (через GBNF-грамматику llama.cpp) со списком границ и пометками
   «интро/аутро/реклама».
5. Эмбеддинги предложений → кривая сходства соседних окон → кандидаты границ (TextTiling-подобно).
6. Слияние: граница, найденная обоими методами, — надёжная; найденная одним — помечается «проверь».
7. LLM, проход 2 — **оценка каждого кандидата**: самодостаточность, оценка 1–10, причина, заголовок, ключевые слова.
8. Доводка: прилипание к паузам с отступом 0.2–0.4 с, проверка длительности (≤60 цель, ≤~120 предел),
   слишком длинные — пометка или попытка ужать (повторный запрос с просьбой выбрать подотрезок).
9. Результат кэшируется в `~/.cache/shortscutter/analysis/<hash>.json`.

Все промпты — в отдельных файлах ресурсов (не в коде), чтобы их можно было итеративно править.

## 5. Превью

- mpv декодирует исходник (VAAPI), рендерит кадр в OpenGL-текстуру.
- Композитор рисует холст: фон (та же текстура + двухпроходный gaussian blur + затемнение), кропы основного видео
  (скругление/рамка/тень — во фрагментном шейдере), растровые слои (из `raster`, кэшируются как текстуры),
  субтитры (растеризуются по текущему времени), баннер.
- Воспроизведение шортса: mpv играет `[in, out]`; при наличии вставки — переключение на второй экземпляр mpv
  с клипом и обратно.
- Оверлей safe zones YouTube Shorts (только в редакторе).
- Для исходников > 1080p — опциональный фоновый прокси (720p, H.264 VAAPI).

## 6. Рендер

Шортс = конкатенация сегментов: `[обложка] → [основное in..at] → [вставка] → [основное at..out]`.
Каждый сегмент проходит один и тот же граф шаблона (вставка — в режиме «весь экран» или «в слот видео»).

Граф `filter_complex` для сегмента:
- `split` исходника → ветка фона (`scale`, `boxblur`/`gblur`, `crop`, затемнение) и ветки кропов основного видео;
- скругление — `geq`-маска или заранее растеризованная маска-PNG + `alphamerge` (предпочтительно маска);
- `overlay` растровых слоёв (PNG из `raster`, тот же растеризатор, что в превью), баннера;
- `ass` — субтитры (сгенерированный файл, таймкоды сдвинуты относительно шортса и вставки);
- `concat` сегментов, аудио — `atrim`/`asetpts` + тишина на обложке.

Кодирование: H.264/HEVC — `*_vaapi` (если доступно) или libx264/libx265; AV1 — libsvtav1; VP9 — libvpx-vp9;
ProRes — prores_ks. Список доступных кодеков определяется при запуске (`ffmpeg -encoders`, `-hwaccels`),
недоступные — неактивны в UI с подсказкой.

Очередь: по умолчанию 2 параллельные задачи (настраивается), прогресс из `-progress pipe:1`,
отмена — завершение процесса и удаление недописанного файла.

## 7. Хранение (XDG)

- `~/.config/shortscutter/` — `settings.toml`, пресеты качества
- `~/.local/share/shortscutter/` — `templates/*.toml`, `library/` (копии ассетов + `library.toml`), `history.toml`, `fonts/`
- `~/.cache/shortscutter/` — `models/` (whisper, LLM, эмбеддинги), `analysis/`, `proxy/`, `tmp/`

## 8. Интерфейс

Вкладки-шаги: **Импорт → Нарезка → Оформление → Экспорт**, плюс **Библиотека** и **Настройки**.

```
┌──────────────┬───────────────────────────────┬──────────────────┐
│ Пачка        │     ПРЕВЬЮ 9:16 (живое)       │ Инспектор        │
│ • video1 ✓   │  [слои двигаются мышкой]      │  Шаблон / Слои   │
│ • video2 ⏳  │                               │  Свойства слоя   │
│              │   ▶ ⏸  00:12 / 00:54          │  Баннер / Вставка│
├──────────────┴───────────────────────────────┴──────────────────┤
│ Таймлайн исходника: [▓ шортс1 ▓]░░[▓ шортс2 ▓]░░░[▓ шортс3 ▓]   │
│ Текст: ...и вот почему Kubernetes [здесь] не нужен для...       │
├─────────────────────────────────────────────────────────────────┤
│ Шортсы: [#1 0:48 ★8 ✓] [#2 1:12 ★6 ⚠] [#3 0:55 ★9 ✓] [+ Ручной] │
└─────────────────────────────────────────────────────────────────┘
```

Тёмная тема. Корректная работа в тайлинге Hyprland (диалоги — отдельные окна с понятным `class`/`title`
для floating-правил).
