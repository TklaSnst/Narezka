# Журнал решений

Формат: дата — решение — причина. Новые записи — внизу.

- 2026-11-12 — Язык Rust (из предложенных C++/Go/Rust). — У Go слабый GUI для видео; C++/Qt тяжелее в разработке и сборке; у Rust есть биндинги к whisper/llama/mpv и `cargo-deb`.
- 2026-11-12 — GUI egui/eframe с бэкендом glow. — Wayland, удобный холст с перетаскиванием, совместимость с OpenGL render API mpv.
- 2026-11-12 — Превью через libmpv, финальный рендер через системный ffmpeg. — Не писать свой плеер; ffmpeg покрывает все нужные кодеки.
- 2026-11-12 — Весь ИИ локально (требование пользователя): whisper.cpp + llama.cpp на Vulkan. — RX 6600 без ROCm; Vulkan работает из коробки.
- 2026-11-12 — Whisper и LLM запускаются последовательно, не одновременно. — 8 ГБ VRAM.
- 2026-11-12 — Нарезка в два прохода LLM + страховка эмбеддингами. — Локальная модель слабее облачной, упрощаем ей задачу.
- 2026-11-12 — Текстовые слои растеризуются одним движком (cosmic-text + tiny-skia) для превью и рендера. — Совпадение превью и результата.
- 2026-11-12 — Координаты в шаблонах — в долях холста. — Шаблон работает при любом выходном разрешении.
- 2026-11-12 — Конфликт имён: продолжать нумерацию; звук на обложке: тишина; экспорт метаданных: выключен; перекрытия шортсов: выключены. — Пользователь делегировал выбор.
- 2026-11-12 — Проект не сохраняется, но транскрипция кэшируется по хэшу файла. — Пользователь отказался от проектов; повторный анализ слишком долгий.
- 2026-11-12 — Репозиторий и вся работа — на ПК пользователя (`~/work/shortscutter`), доступ по SSH-мосту. — Там GPU, ffmpeg с VAAPI и Hyprland; спайки и замеры имеют смысл только на этой машине.
- 2026-11-12 — Поддержку кодека определять пробным кодированием, а не по `ffmpeg -encoders`. — `av1_vaapi` есть в сборке, но RX 6600 его не умеет.
- 2026-11-12 — Whisper: large-v3-turbo F16 + встроенный Silero VAD; medium/small не нужны. — ×17 реального времени, 2 ГБ VRAM; VAD убирает галлюцинации и даёт пунктуацию. Q5_0 — запас для слабых карт.
- 2026-11-12 — whisper.cpp подключаем своим `-sys` крейтом (bindgen) с закреплённой версией, а не `whisper-rs`. — В `whisper-rs` старый whisper.cpp без таймкодов токенов на исходной шкале при VAD.
- 2026-11-12 — Приложение выставляет `GGML_VK_DISABLE_HOST_VISIBLE_VIDMEM=1` до инициализации ggml. — Без ReBAR ggml кладёт буферы в системную RAM: whisper ×5 медленнее, llama pp −16%.
- 2026-11-12 — LLM по умолчанию (предварительно): Qwen3.5-9B UD-Q4_K_XL без режима рассуждений; запасная — Ornith-1.0-9B (тот же размер). Окончательно — после оценки пользователем на его ролике. — Сравнение 4 моделей в шаге 0.3: Gemma 4 12B точнее по границам, но 7.3 ГБ VRAM и не различает оценки; LFM2.5 путает номера; рассуждения с грамматикой не завершаются.
- 2026-11-12 — Ответы LLM — через JSON-схему (llama.cpp строит GBNF), рассуждения выключены; номера предложений в ответе проверяются кодом. — JSON валиден всегда, но смысловые ошибки (номер вне окна) бывают.
- 2026-11-12 — Кодирование по умолчанию: `h264_vaapi` VBR 12 Мбит/с; без VAAPI — libx264 veryfast 12 Мбит/с. HEVC/AV1/VP9/ProRes — по выбору. — Шаг 0.4: время рендера определяет граф, а не кодировщик; `hevc_vaapi` на RX 6600 не лучше H.264 по качеству; YouTube всё равно перекодирует.
- 2026-11-12 — Очередь рендера: 2 параллельные задачи по умолчанию. — Шаг 0.4: граф использует ~2.5 ядра из 6; две задачи ×1.35, три — ×1.47.
- 2026-11-12 — Превью: libmpv render API в свою FBO-текстуру, показ через egui; запасной вариант (libav/GStreamer) не нужен. — Шаг 0.5: 60 к/с на 1080p и 4K (HEVC/AV1 VAAPI), точный seek в пределах кадра, бесшовная петля отрезка.
- 2026-11-12 — С libmpv работаем только асинхронно (observe_property, command_async), `BLOCK_FOR_TARGET_TIME=0`. — Синхронные вызовы из GL-потока: взаимное ожидание и seek 200–500 мс вместо 36–90; блокирующий render вешает UI навсегда.
- 2026-11-12 — Blur фона в превью — в ¼ разрешения холста. — 0.4 мс против 7 мс (p95 14 мс) на полном, визуально не отличается.
- 2026-11-12 — FFI к libmpv — свои объявления (~20 функций), без сторонних крейтов. — Нужны render API и async-вызовы; объём маленький, как и у whisper.
- 2026-11-12 — Пакеты workspace называются `sc-<модуль>` (`sc-core`, `sc-render`…), бинарник — `shortscutter`. — `core` конфликтует со встроенным крейтом Rust; единый префикс проще, чем исключение для одного.
- 2026-11-12 — Id исходников и шортсов — UUID v4. — Пачка не сохраняется, но сериализуется (отладка, «как в прошлый раз»); счётчики пришлось бы восстанавливать после чтения.
- 2026-11-12 — Проверка шортса (границы, длительность исходника, перекрытия) — в `Batch`, а не в UI. — Одни правила для ручной нарезки и для результатов LLM.
- 2026-11-12 — Битый `settings.toml` не блокирует запуск: переименовывается в `settings.toml.bad`, берутся дефолты; запись атомарная (tmp + rename). — Файл правится руками.
- 2026-11-12 — Хэш исходника — blake3 от размера + трёх кусков по 1 МиБ (начало, середина, конец). — Ключ кэша транскрипции; многочасовой ролик целиком читать долго, а совпадение размера и трёх кусков у разных роликов практически исключено.
- 2026-11-12 — Ошибки исходника в модели — i18n-ключ, подробности — в лог. — Тексты UI только через ключи; при смене языка сообщение переводится заново.
- 2026-11-12 — Файлы можно передать аргументами командной строки; drag-and-drop на Wayland пока недоступен. — winit 0.30 не реализует DnD на Wayland; диалог + аргументы закрывают сценарий.
- 2026-11-12 — FFI к libmpv — отдельный крейт `sc-mpv` без зависимости от egui. — Обёртка нужна и превью, и, возможно, второму экземпляру для вставок; колбэк пробуждения — замыкание.
- 2026-11-12 — Геометрия кропа (фон «cover» × scale, подрезка кропа слоя под пропорции `dest`) — функции в `sc-core`, общие для превью и рендера. — `render` и `compositor` не зависят друг от друга; одна формула — совпадение превью и результата. Растягивания видео нет: лишнее срезается по центру.
- 2026-11-12 — Слои поверх фона в превью рисует egui (текстура кадра + `RectShape` со скруглением); GL-шейдеры — только для blur. — Хватает для этапа 1; свой шейдер слоёв — когда понадобятся рамки/тени (этап 3).
- 2026-11-12 — Выбор шортса в «Нарезке» = петля `ab-loop` на его границы; перемотка за пределы снимает выбор. — Превью шортса без отдельного режима; петля бесшовная (шаг 0.5).
- 2026-11-12 — Рендер пишет в скрытый `.<имя>.part` и переименовывает только после успеха. — Отменённый или упавший рендер не оставляет файл с «настоящим» именем, а нумерация «продолжить» не видит недописанные файлы.
- 2026-11-12 — Маска скругления для `alphamerge` — PGM, генерируется в `sc-render` (SDF со сглаживанием), а не PNG из `raster`. — Без зависимостей и раньше, чем появится растеризатор; формат читает любой ffmpeg.
- 2026-11-12 — Кодировщик для задачи выбирает приложение по `Capabilities` и передаёт в `RenderJob`; `sc-render` от `sc-media` не зависит. — Рендер тестируется без пробного кодирования; правило выбора одно — `encoder_for`.
- 2026-11-12 — Пока очереди нет, шортсы рендерятся последовательно в одном потоке. — Очередь на 2 задачи — этап 7; для каркаса достаточно прогресса и отмены.
- 2026-11-13 — whisper.cpp — git-сабмодуль `third_party/whisper.cpp` (d2c6f05), собирается статически из `build.rs` (`cmake`, Vulkan, без OpenMP). — Версия закреплена в репозитории, в пакете не нужна отдельная libwhisper.so; OpenMP не нужен, считает GPU.
- 2026-11-13 — Звук для whisper — `s16le` из ffmpeg прямо в память, без временного WAV. — `f32le` даёт стерео→моно без нормировки: whisper теряет пунктуацию и медленнее в 1.7 раза; WAV на диске не нужен — whisper всё равно берёт весь буфер.
- 2026-11-13 — Транскрипт кэшируется отдельным файлом `<hash>.transcript.json`, хранит оба таймкода слова (токены и DTW). — Перезапуск LLM-нарезки не требует whisper; выбор токены/DTW не требует перераспознавания. DTW требует выключить flash attention (+~10% времени).
- 2026-11-13 — Словарь терминов — обычный initial prompt, без `carry_initial_prompt`. — С ним whisper терял фразы и точки, растягивал сегменты до 15–20 с.
- 2026-11-13 — Анализ стартует автоматически после импорта, ролики — по одному; модель whisper грузится на каждый ролик и выгружается после. — Загрузка 1–4 с против минут распознавания; VRAM гарантированно свободна для LLM.
- 2026-11-13 — Модели качаются с Hugging Face в `~/.cache/shortscutter/models` с докачкой и проверкой SHA-256; можно указать свой файл whisper. — Требование «модели не в пакете» (этап 8); SHA-256 HF отдаёт в `x-linked-etag`.
- 2026-11-13 — llama.cpp — сабмодуль `third_party/llama.cpp` (b11384); `sc-llama` собирает `llama-server` (статически, Vulkan, без веб-интерфейса и OpenSSL) и запускает его отдельным процессом на свободном порту localhost. — Статическая линковка рядом с whisper дала бы две копии ggml в одном процессе; процесс проще выгрузить из VRAM (kill), его падение не роняет приложение; HTTP API уже умеет JSON-схемы и эмбеддинги. Та же версия, что в замерах 0.3.
- 2026-11-13 — Эмбеддинги — Qwen3-Embedding-0.6B Q8_0 (0.64 ГБ, качается как остальные модели), без инструкции-префикса, контекст сервера 2048. — Многоязычная, в GGUF у Qwen; на сценариях с разметкой префикс-инструкция полноту не улучшил; KV 224 МБ вместо 896 при той же скорости.
- 2026-11-13 — TextTiling по средним векторам окон ±45 с, порог глубины `mean − 0.5·std`, не ближе 20 с. — Спайк `spikes/06-embed`: полнота 0.65/0.75 на двух сценариях; меньший порог даёт больше кандидатов — это страховка LLM, пропуск хуже лишнего кандидата.
- 2026-11-13 — Предложение: конец по `.!?…` или паузе ≥1.2 с, длиннее 30 с делится по лучшей паузе/запятой; повторы не удаляются, а помечаются. — Живая речь без точек; длинные «предложения» мешают и LLM, и прилипанию границ; удалять текст до LLM рискованно — решит проход 1.
- 2026-11-13 — `silencedetect` не используем; паузы — промежутки между словами, уточнённые VAD. — VAD уже есть в транскрипте и отличает речь от музыки, `silencedetect` — нет.
- 2026-11-13 — Промпты и схемы нарезки — ресурсы крейта `sc-analysis` (`crates/analysis/prompts/`, вшиты в бинарник); одноимённые файлы в `~/.config/shortscutter/prompts/` их перекрывают. Хэш текстов — часть ключа кэша нарезки. — Итерация промптов вместе с пользователем без пересборки; правка промпта сама делает старую нарезку устаревшей.
- 2026-11-13 — Слияние LLM и эмбеддингов: граница LLM «подтверждена», если граница эмбеддингов ближе 5 с; границы только эмбеддингов режут лишь блоки длиннее 120 с; содержательные блоки короче 20 с склеиваются с соседом через неподтверждённую границу (при равенстве — с более похожим по среднему вектору), если вместе ≤90 с. В проходе 1 `maxItems` = окно/25 с, упёрлась в лимит — остаток окна спрашивается заново. — Точность эмбеддингов ~0.5: как самостоятельные границы они дробят текст; при ±10 с «подтверждены» оказывались почти все границы (случайные совпадения). LLM дробит окно на блоки по 1–2 предложения (2000 токенов ответа); склейка только по сходству роняла полноту с 0.92 до 0.54.
- 2026-11-13 — Пометка «проверь» (`Flag::Unsure`) — только если кандидат реально начинается/кончается на неподтверждённой границе блока; длиннее цели после повторного запроса «выбери короче» — `TooLong`, кандидат не выбрасывается. — Пользователь решает на экране «Нарезка»; спецификация допускает до ~120 с.
- 2026-11-13 — Анализ ролика в приложении — одна задача: распознавание → эмбеддинги → LLM; серверы эмбеддингов и LLM запускаются по очереди и завершаются сразу после работы. Транскрипт показывается до окончания нарезки; без моделей нарезки распознавание всё равно идёт. Кэш — `analysis/<hash>.cut.json`, новый транскрипт удаляет старую нарезку. — VRAM 8 ГБ; нарезку можно повторить отдельно (кнопка ✂) без whisper.
- 2026-11-13 — Кандидаты нарезки копируются в пачку как `Short` со статусом `Candidate` и `auto = true`; повторная нарезка заменяет авто-шортсы ролика, кроме принятых; новый кандидат, больше чем наполовину покрытый принятым шортсом, не добавляется. — Одна модель для ручных и предложенных шортсов: таймлайн, превью-петля, правка краёв и экспорт (берёт только `Accepted`) работают без изменений; решения пользователя переживают «нарезать заново».
- 2026-11-13 — Перекрытия проверяются только между принятыми шортсами; опция `Batch::allow_overlap` (по умолчанию выключена) снимает и это. Кандидаты и отклонённые могут лежать где угодно. — Иначе кандидат мешал бы отметить вручную шортс на его месте; конфликт решается в момент «Принять».
- 2026-11-13 — Ручные зоны пропуска — `Source::skip`. В нарезке предложения с серединой в зоне скрыты от LLM (как повторы whisper), блоки режутся по краям зон (`BlockKind::Skip`, граница `Found::Manual` — надёжная); зоны — часть ключа кэша (`Cutting::skips`), «нарезать заново» повторяет оба прохода. — Модель не тратит время и лимит блоков на выкинутое; кэшировать проход 1 отдельно ради экономии ~⅓ времени пока не стоит.
- 2026-11-13 — Текст под таймлайном — 6 сегментов whisper вокруг курсора (листается, когда курсор уходит за них; колесо — вручную), слово — кликабельная метка. — Сегменты уже есть в транскрипте; на часовом ролике ~9000 слов — рисуем только окно, без раскладки всего текста каждый кадр.
- 2026-11-13 — Всё, что не зависит от кадра видео (фон-градиент и фон-картинка, тени и рамки слоёв видео, фигуры, картинки, дальше — текст), растрирует `sc-raster` в размере холста; превью загружает эти растры текстурами, рендер пишет их PAM-файлами и накладывает `overlay`. — Одна картинка на обе стороны: совпадение не зависит от того, как то же самое нарисовали бы GL и ffmpeg. PAM (как PGM для масок) — без зависимостей, с альфой.
- 2026-11-13 — Превью собирает весь холст в свою текстуру размером с область на экране (шейдер слоя: кроп, SDF-скругление, затемнение, premultiplied), egui показывает одну текстуру. Заменяет решение «слои рисует egui». — Нужны рамки/тени/z-order нескольких видео; холст целиком можно прочитать для сравнения с рендером; оверлеи редактора рисуются egui поверх.
- 2026-11-13 — Длины в шаблоне (радиусы, рамки, тени, кегль) — в долях ширины холста; рамка — внутрь слоя. — Шаблон не зависит от выходного разрешения; рамка не меняет геометрию, которую пользователь двигает мышкой.
- 2026-11-13 — Позиция и кроп видео в превью — те же чётные пиксели, что у рендера (`to_pixels_even`, `main_video_crop_px`). — Расхождение в 1 px между тенью/рамкой (растр) и видео было бы заметно на тонкой рамке.
- 2026-11-13 — Темп сгенерированного фона (цвет, картинка, видео) = частота вывода или исходника (`RenderJob::src_fps`). — Темп графа задаёт база `overlay`; источник `color` по умолчанию 25 к/с — шортсы с цветным фоном выходили в 25 к/с.
- 2026-11-13 — Видео-фон в превью — второй экземпляр mpv (по кругу, без звука, пауза вместе с основным), в рендере — `-stream_loop -1` и cover через `scale=…:force_original_aspect_ratio=increase,crop`. — Синхронизация по времени фону не нужна; размер видео-фона рендеру заранее неизвестен.
- 2026-11-14 — Текст растрируется из векторных контуров глифов (cosmic-text: раскладка; swash: контуры без хинтинга; tiny-skia: заливка, обводка-штрих, плашки), а не готовыми битмапами глифов. — Обводка любой толщины и плашки — одной библиотекой; форма не зависит от хинтинга и кегля.
- 2026-11-14 — Шрифт слоя — имя семейства системы, начертание можно дописать в конец («… Bold»). — Модель не меняется до шага 3.4 (свои шрифты и выбор в интерфейсе).
- 2026-11-14 — Не влезающий в прямоугольник текст уменьшается (до 40% кегля), а не обрезается. — Заголовки от LLM разной длины; слой задаёт место, а не точный кегль.
