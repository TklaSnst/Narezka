# Требования (SPEC)

Источник — интервью с пользователем 2026-11-12. Пункты, на которые пользователь не ответил,
решены разработчиком и помечены **[по умолчанию]**.

## 1. Общее

- Платформа: Linux desktop; основная система — Ubuntu + Hyprland, совместимость с другими дистрибутивами желательна.
- Упаковка: пока только `.deb`; Flatpak/AppImage — позже.
- Язык интерфейса: русский и английский, переключается в настройках (по умолчанию — русский).
- Сохранение проекта (закрыл/открыл) **не нужно**. Кэш транскрипций при этом допустим (это не проект).
- Пакетная обработка: можно загрузить несколько длинных роликов, оформление и output общие для пачки.
- Загрузка по ссылке YouTube **не нужна** — только локальные файлы.
- Исходники разные по длительности, разрешению, fps, контейнеру.
- Приоритет MVP: **нарезка по смыслу** и **нормальный внешний вид**.
- Баланс рендера: середина между скоростью и качеством.

## 2. Нарезка

- Отрезки определяются **по смыслу** (законченная мысль). Потери (куски, не годные в шортс) допустимы.
- Длина: цель ≤ 60 с; если иначе мысль обрывается — до ~120 с.
- Перекрытия шортсов: по умолчанию запрещены, включаются опцией. **[по умолчанию]**
- Пропуск фрагментов (интро, аутро, спонсорские блоки) — нужен: и автоматически, и ручной разметкой.
- Предпросмотр каждого шортса до рендера, правка границ, удаление/добавление/разделение/объединение.
- Предпросмотр — живой, без промежуточного рендера (для 4K допускается скрытый прокси).
- Субтитры и анализ — по русской речи.

## 3. Внешний вид

- Шаблоны: несколько встроенных + создание/сохранение своих.
- Редактирование положения элементов — **мышкой** прямо в превью (плюс панель свойств для точной правки).
- Элементы: фон (размытие / цвет / градиент / картинка / видео), основное видео (кроп, позиция, масштаб),
  опциональные скругление, рамка, тень.
- Опциональные текстовые слои: заголовок, ник/вотермарк, логотип, «Часть N».
- Опциональные субтитры: позиция мышкой, цвет, шрифт, размер.
- Превью: живое, приблизительное (полное совпадение с рендером не требуется, но к нему стремимся).
- Встроенные шаблоны строятся по референсам, см. `docs/references/README.md`.

## 4. Баннеры и вставки

- **Баннер** — изображение поверх видео (PNG/JPG/WebP/GIF/видео с альфой). Висит весь шортс, без анимации.
  Перемещается и масштабируется мышкой. Один на пачку.
- Опционально — текст рядом с баннером (промокод/ссылка).
- **Вставка** — рекламный клип. Время вставки задаёт человек **для каждого шортса**.
  Основное видео приостанавливается, идёт вставка, затем продолжается.
- Вставки бывают и вертикальные, и горизонтальные — ориентация определяется автоматически, можно переопределить.
- Показ баннера во время вставки — настройка ассета-вставки (бывает по-разному).
- Опции «без баннера» и «без вставки» — на уровне пачки и отдельного шортса.
- **Библиотека ассетов** (баннеры, вставки, шрифты, картинки) + история использования.
- При новой пачке приложение предлагает «Сделать как в прошлый раз?».

## 5. Обложка-кадр

- YouTube берёт первый кадр шортса как превью → можно выбрать кадр (из шортса, из исходника или картинку),
  который дублируется в начало.
- На кадр опционально добавляются тексты и изображения.
- Длительность — несколько кадров (настраивается). Звук на обложке — тишина. **[по умолчанию]**

## 6. Output

- Контейнеры/кодеки: MP4 (H.264, H.265, AV1), WebM (VP9, AV1), MOV (ProRes 422 Proxy/LT/Std/HQ, 4444).
- Качество: пресеты + раскрывающиеся расширенные настройки (CRF/QP, битрейт, кодировщик GPU/CPU, профиль, GOP, аудио).
  Свои пресеты можно сохранять.
- Разрешение: выбор, по умолчанию 1080×1920. fps: как в исходнике или 30/60.
- Папка вывода — выбор, без подпапок.
- Имена: `<пользовательский ввод>_<n>.<ext>`, нумерация с 1, без ведущих нулей.
- Конфликт имён: по умолчанию продолжать нумерацию; в настройках — «спросить» / «перезаписать». **[по умолчанию]**
- Очередь рендера: прогресс, пауза, отмена; ошибка одного файла не останавливает остальные.
- Уведомление по окончании — опционально.
- Экспорт метаданных (`name_n.txt`: заголовок, таймкоды, текст, хэштеги) — опция, по умолчанию выключена. **[по умолчанию]**

## 7. Не нужно (явно отказался)

Хук-интро, прогресс-бар, авто-слежение за лицом, удаление пауз, автозагрузка на YouTube,
undo/redo и горячие клавиши (как требование), сохранение проектов, загрузка по ссылке.
