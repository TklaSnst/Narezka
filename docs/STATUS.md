От пользователя нужно (не блокирует этап 1):
1. **Запустить спайк превью на Hyprland** (из своей сессии):
   `cd ~/work/shortscutter/spikes/05-preview && ./target/release/preview-spike ~/work/twitch/cache/2847668151/seg00_Counter-Strike.mp4`
   — видео и размытый фон видны, плавно, жёлтая рамка тащится мышкой (колесо — размер), «▶ отрезок» и ±кадр работают.
2. Таймкоды слов: жёлтая дорожка (токены) или зелёная (DTW) в `spikes/out/02/compare-timestamps.mp4`.
3. Нарезка LLM: `spikes/out/03/qwen35-9b.report.md` (и `ornith-9b`, `gemma4-12b`) — подтвердить модель (сейчас Qwen3.5-9B).
4. Длинный ролик с канала **с записью голоса** (путь к файлу) — повторить 0.2 и 0.3 на живой речи.
5. По желанию — `spikes/out/04/full/h264_vaapi-12M.mp4` (черновой шортс, качество GPU-кодирования).
6. Проверить на Hyprland кнопку «Добавить видео…» (диалог через xdg-desktop-portal): `cargo run --release -p shortscutter`.
7. Там же — вкладка «Нарезка» **мышью** (в headless проверена только клавиатура): клик/перетаскивание по таймлайну,
   колесо (масштаб), Shift+колесо, растягивание краёв выбранного шортса, клики по полосе шортсов.
8. Вкладка «Экспорт»: выбрать папку (диалог портала), отрендерить 3 шортса, открыть файлы плеером — совпадают ли с превью;
   нажать «Отмена» посреди рендера — недописанный файл должен исчезнуть.
9. Анализ (шаг 2.1): добавить ролик — в «Импорте» пойдут «Поиск речи» → «Речь N%», затем «Распознано: N слов».
   Проверить мышью «Стоп», «⟳» (распознать заново) и удаление ролика во время анализа; повторное добавление — мгновенно из кэша.
   В «Настройках» вписать словарь терминов (имена, Lumen VPN…) и распознать ролик с голосом заново — правильно ли пишутся термины,
   нет ли повторяющихся фраз (петли whisper).
10. Нарезка (шаг 2.3): в «Настройках» скачать модели нарезки (или они уже есть), добавить ролик — после «Распознано» пойдут
    «Структура текста» → «Загрузка LLM» → «Нарезка N%», затем «N кандидатов». Проверить «Стоп» на нарезке и ✂ (нарезать заново).
    Таблицы кандидатов по сценариям — `spikes/out/07/net.md`, `scam.md`: похожи ли блоки на законченные мысли, хороши ли заголовки.
11. Экран «Нарезка» (шаг 2.4) мышью: ✔/✖ в списке, клик по словам (начало → конец), Enter, зона из отметок (Z) и 🗑,
    «✂ Нарезать заново» с ручной зоной (кандидатов в зоне быть не должно, принятые остаются), «Разрешить перекрытия».
12. Шаблоны (шаг 3.1): `SC_TEMPLATE=tools/templates/split.toml cargo run --release -p shortscutter` (и `terminal`, `gradient`) —
    превью совпадает с отрендеренным шортсом, при воспроизведении нет рывков.
13. Текст (шаг 3.2): `SC_TEMPLATE=tools/templates/text.toml cargo run --release -p shortscutter` — выбрать шортс с заголовком:
    заголовок и «Часть N» в капсуле меняются при выборе другого шортса; отрендерить — текст как в превью.
14. Редактор (шаг 3.3), вкладка «Оформление» с тем же `text.toml`: клик по слою, перетаскивание, ручки (Shift на углу), линии привязки,
    «Сетка», «Зоны Shorts» (⚠ у слоёв), кроп видео (кнопка «Кроп» или Alt + перетаскивание, колесо), Ctrl+Z; панель справа —
    поменять цвет/кегль/тень, фон. Плавно ли тянется слой с тенью/текстом, не мешает ли Hyprland Alt-перетаскиванию.
