9. Анализ (шаг 2.1): добавить ролик — в «Импорте» пойдут «Поиск речи» → «Речь N%», затем «Распознано: N слов».

10. Нарезка (шаг 2.3): в «Настройках» скачать модели нарезки (или они уже есть), добавить ролик — после «Распознано» пойдут

12. Шаблоны (шаг 3.1): `SC_TEMPLATE=tools/templates/split.toml cargo run --release -p shortscutter` (и `terminal`, `gradient`) —

13. Текст (шаг 3.2): `SC_TEMPLATE=tools/templates/text.toml cargo run --release -p shortscutter` — выбрать шортс с заголовком:
    заголовок и «Часть N» в капсуле меняются при выборе другого шортса; отрендерить — текст как в превью.
14. Редактор (шаг 3.3), вкладка «Оформление» с тем же `text.toml`: клик по слою, перетаскивание, ручки (Shift на углу), линии привязки,

    поменять цвет/кегль/тень, фон. Плавно ли тянется слой с тенью/текстом, не мешает ли Hyprland Alt-перетаскиванию.
15. Шрифты (шаг 3.4), там же: у текста — список «Шрифт» (поиск, встроенные/системные), начертание; «Свой шрифт…» — выбрать .ttf/.otf

16. **Шаблоны (шаг 3.5)** на своём ролике: `cargo run --release -p shortscutter`, «Оформление» → список «Шаблон» — пройти все шесть

    отрендерить два шортса — у одного правка есть, у другого нет.
17. **Субтитры (шаг 4.1)**: `cargo run --release -p shortscutter`, ролик с речью, выбрать шортс в «Нарезке», ▶ — субтитры в превью

    ключевое слово (подчёркнуто, в субтитрах — цветом). Нравится ли разбиение на фразы и как держится подсветка.
18. **Субтитры в рендере и правка (шаг 4.2)**: там же, шаблон с субтитрами, в «Нарезке» под списком шортсов — «Субтитры шортса»:
    исправить фразу (Enter), добавить/убрать слово, ↺; отрендерить шортс на вкладке «Экспорт» и сравнить с превью — те же фразы,
    цвета, подсветка в такт речи. Примеры рендера на CS-ролике — `spikes/out/10/highlight.png`, `reveal.png` (и `.mp4` рядом).
19. **Библиотека (шаг 5.1)**: `cargo run --release -p shortscutter`, вкладка «Библиотека» → «Добавить файлы…» (портал, можно
    несколько): баннер Lumen (PNG с прозрачностью), рекламный ролик, свой шрифт. Миниатюры, тип угадан (баннер/вставка/шрифт),
    шахматка под прозрачным; тот же файл ещё раз — «уже есть»; теги на русском («реклама, lumen vpn» → `#lumen-vpn`), поиск
    по-русски и по `#тегу`, чипы тегов; переименовать, сменить тип, удалить. После перезапуска всё на месте.
