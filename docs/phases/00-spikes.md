# Этап 0 — Проверка технологий

**Цель:** до написания приложения убедиться, что выбранный стек работает на машине пользователя
(Ubuntu + Hyprland + RX 6600), и выбрать LLM. Результат этапа — цифры и решения, а не продукт.

**Читать перед началом:** `docs/ARCHITECTURE.md` §1, §4, §5.

Код спайков — в `spikes/` (выбрасываемый, в workspace приложения не входит).
Результаты замеров — в раздел «Результаты» этого файла.

## Шаг 0.1 — Окружение
- [ ] `git init`, `.gitignore` (target/, модели, тестовые видео)
- [ ] Проверить версии: rustc/cargo, ffmpeg (`-encoders`, `-hwaccels`, наличие libass, libsvtav1, libvpx, prores_ks), libmpv-dev, Vulkan (`vulkaninfo`), VAAPI (`vainfo`)
- [ ] Список недостающих пакетов → предложить пользователю команду `apt install` (не ставить без подтверждения)
- [ ] Записать итог в «Результаты»

## Шаг 0.2 — Whisper на Vulkan
- [ ] Собрать whisper.cpp (или `whisper-rs` с Vulkan) — выяснить, что проще и стабильнее
- [ ] Прогнать large-v3-turbo на 10-минутном фрагменте тестового ролика: время, загрузка VRAM, качество русского, таймкоды слов
- [ ] Сравнить с medium/small по скорости и качеству

## Шаг 0.3 — Выбор LLM
- [ ] Собрать llama.cpp с Vulkan
- [ ] Подготовить черновой промпт прохода 1 (границы тем) и прохода 2 (оценка) — сохранить в `spikes/prompts/`
- [ ] Прогнать 2–3 модели ~7–9B с хорошим русским (актуальные на момент выполнения) на транскрипте из 0.2
- [ ] Оценить вместе с пользователем: насколько границы совпадают с «законченными мыслями»; скорость; VRAM
- [ ] Проверить GBNF/JSON-грамматику — ответ всегда валиден
- [ ] Выбрать модель и квантизацию → `DECISIONS.md`

## Шаг 0.4 — Кодирование
- [ ] `h264_vaapi` и `hevc_vaapi`: 60-секундный 1080×1920 фрагмент, время и качество против libx264
- [ ] libsvtav1, libvpx-vp9, prores_ks — время на тот же фрагмент (для оценки, что показывать в UI)
- [ ] Проверить граф: blur-фон + кроп + overlay PNG + `ass` — работает в одном `filter_complex`

## Шаг 0.5 — Превью
- [ ] Минимальное eframe(glow)-окно на Hyprland
- [ ] libmpv render API → текстура → нарисовать в egui, поверх — прямоугольник, который тащится мышкой
- [ ] Blur-шейдер по той же текстуре (двухпроходный) — FPS на 1080p и 4K исходнике
- [ ] Воспроизведение отрезка [in, out] и точный seek
- [ ] Если не работает — проверить запасной вариант (см. риски в `PLAN.md`) и записать решение

## Критерии приёмки этапа
- Все пять шагов либо подтверждены, либо есть записанная замена.
- Модель LLM выбрана, пользователь видел пример нарезки на своём ролике.
- `ARCHITECTURE.md` исправлен там, где гипотезы не подтвердились.
