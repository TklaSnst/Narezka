# Этап 1 — Каркас приложения

**Цель:** работающее приложение, в котором можно загрузить видео, вручную отметить отрезок и
отрендерить его в простой вертикальный шортс. Это фундамент для этапов 2 и 3.

**Читать перед началом:** `docs/ARCHITECTURE.md` §2, §3, §6, §7; «Передача дальше» этапа 0.

## Шаг 1.1 — Workspace и модель
- [ ] Cargo workspace с crates из `ARCHITECTURE.md` §2 (пустые там, где пока не нужны)
- [ ] `core`: типы Batch / Source / Short / Template (минимальный: фон-blur + одно основное видео) с serde
- [ ] `i18n`: Fluent, файлы `ru.ftl`/`en.ftl`, переключение языка
- [ ] Пути XDG, `settings.toml` (чтение/запись с дефолтами)
- [ ] Тесты сериализации модели

## Шаг 1.2 — Медиа и импорт
- [ ] `media`: ffprobe → длительность, разрешение, fps, аудио; хэш файла (быстрый: размер + куски)
- [ ] Проверка возможностей ffmpeg при запуске → структура `Capabilities`
- [ ] Экран «Импорт»: выбор нескольких файлов (диалог + drag-and-drop), список пачки со статусами

## Шаг 1.3 — Плеер и таймлайн
- [ ] Интеграция подхода превью, выбранного на шаге 0.5, в `app`
- [ ] Таймлайн исходника: перемотка, масштаб, отображение шортсов цветными блоками
- [ ] Ручное создание шортса: поставить in/out, удалить, выбрать
- [ ] Воспроизведение выбранного шортса в превью 9:16 (минимальный шаблон: blur-фон + видео по центру)

## Шаг 1.4 — Простой рендер
- [ ] `render`: генерация `filter_complex` для минимального шаблона, H.264 (VAAPI или libx264 по `Capabilities`)
- [ ] Папка вывода, базовое имя, нумерация `<name>_1.mp4`, политика конфликтов «продолжить нумерацию»
- [ ] Прогресс одного рендера в UI, отмена
- [ ] Ручная проверка: 3 шортса из реального ролика открываются и выглядят как в превью

## Критерии приёмки
- Пользователь может вручную нарезать ролик на шортсы и получить файлы.
- Приложение запускается на Hyprland без ошибок, интерфейс на русском и английском.
