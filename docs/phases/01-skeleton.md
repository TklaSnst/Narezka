# Этап 1 — Каркас приложения

**Цель:** работающее приложение, в котором можно загрузить видео, вручную отметить отрезок и
отрендерить его в простой вертикальный шортс. Это фундамент для этапов 2 и 3.

**Читать перед началом:** `docs/ARCHITECTURE.md` §2, §3, §6, §7; «Передача дальше» этапа 0.

## Передача дальше

### Шаг 1.1 (2026-11-12) — сделан
- Workspace в корне репо, `crates/*`; спайки исключены (`exclude = ["spikes"]`). Пакеты называются `sc-<имя>`
  (`sc-core`, `sc-i18n`…), бинарник — пакет `shortscutter` в `crates/app`. Имя `core` занято встроенным крейтом Rust.
- `sc-core`: `geometry` (`Rect` в долях, `Color` ↔ `#RRGGBB[AA]`), `template` (`Template::minimal()` — blur + 16:9 по центру,
  `validate()`, TOML с тегом `type`), `batch` (`Batch`/`Source`/`Short`/`OutputSettings`, id — UUID; `add_short`/`update_short`
  проверяют границы, длительность исходника и перекрытия; отклонённые шортсы перекрытиям не мешают), `paths` (XDG,
  `Paths::with_root` для тестов), `settings` (`#[serde(default)]` — недостающие поля из дефолтов, атомарная запись,
  битый файл → `settings.toml.bad` + дефолты).
- `sc-i18n`: `I18n::tr/tr_args`, `locales/{ru,en}.ftl` встроены `include_str!`; тест сверяет наборы ключей RU/EN;
  русские плюралы работают через CLDR (`one/few/many`). Изоляция направления выключена — egui рисует U+2068 как мусор.
- `shortscutter` (app): вкладки-заглушки, переключение языка в «Настройках» сразу сохраняет `settings.toml`.
- Проверено: `cargo test --workspace` (18 тестов), `cargo clippy` без предупреждений, окно на RU/EN в headless sway.

Неочевидное:
- egui/eframe 0.36: `App::ui(&mut self, ui, frame)` вместо `update(ctx)`, панели — `egui::Panel::top/bottom(...).show(ui, …)`.
- В headless sway eframe пишет `Failed to initialize arboard clipboard … X11` — безвредно (нет X11); на Hyprland проверить буфер обмена.
- `Settings::allow_overlaps` пока не используется моделью — `Batch` перекрытия запрещает всегда; подключить, когда появится UI настройки.
- clippy поставлен в тулчейн пользователя (`rustup component add clippy`).

### Шаг 1.2 (2026-11-12) — сделан
- `sc-media`: `probe()` — ffprobe JSON → `MediaInfo` (пропускает обложки `attached_pic`, учитывает поворот из
  `side_data_list`/`tags.rotate`, fps из `avg_frame_rate`, иначе `r_frame_rate`); `quick_hash()` — blake3 от размера и трёх
  кусков по 1 МиБ, формат `<размер hex>-<32 hex>`; `Capabilities::detect()` — версия, `/dev/dri/renderD*`, обязательные
  фильтры, пробное кодирование 3 кадров каждым кандидатом параллельно (~0.4 с), `encoder_for(codec, EncoderPref)`.
  Все внешние вызовы — через `process::run` с таймаутом и `stdin=null`.
- App: модули `jobs` (поток на задачу → mpsc → `request_repaint`) и `import`. Проверка ffmpeg в фоне при старте,
  итог в строке состояния и в «Настройках» (таблица кодировщиков ✔/✖). Импорт: диалог `rfd` (портал), drag-and-drop,
  **файлы из аргументов командной строки** (`shortscutter a.mp4 b.mkv`). Дубли отсекаются по пути, а после хэша — и по
  содержимому. Ошибки исходника хранятся как i18n-ключ в `SourceStatus::Failed` (язык переключается без потерь).
  В `Settings` появилось `last_import_dir`.
- Проверено: 29 тестов (`sc-media` — 8 модульных + 2 на настоящем ffmpeg), clippy чистый, скриншот в headless sway:
  ролик 1:50:50 1920×1080 60 к/с читается, wav — «В файле нет видео», битый mp4 — «не распознан».
  На ПК: h264/hevc_vaapi ✔, av1_vaapi ✖, все CPU-кодировщики ✔, фильтры все есть.

Неочевидное:
- **winit 0.30.13 не поддерживает drag-and-drop на Wayland** — на Hyprland перетаскивание не сработает (на X11/XWayland
  работает). Подсказка о перетаскивании на Wayland скрыта. Вернуться, когда eframe перейдёт на winit с DnD для Wayland.
- `ffmpeg -filters` в 8.x без разделителя `---` (у `-encoders` он есть): список разбирается по строкам «флаги имя описание»,
  строки легенды (`X = …`) пропускаются.
- egui 0.36: `DroppedFile` — трейт (`f.path()`), а не структура.
- rustfmt в тулчейне не установлен (`rustup component add rustfmt`) — форматирование вручную.
- Диалог выбора файлов на Hyprland идёт через xdg-desktop-portal (FileChooser есть в `gtk.portal`); в headless sway не проверялся.
