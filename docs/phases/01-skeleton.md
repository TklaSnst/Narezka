# Этап 1 — Каркас приложения

**Цель:** работающее приложение, в котором можно загрузить видео, вручную отметить отрезок и
отрендерить его в простой вертикальный шортс. Это фундамент для этапов 2 и 3.

**Читать перед началом:** `docs/ARCHITECTURE.md` §2, §3, §6, §7; «Передача дальше» этапа 0.

## Шаг 1.1 — Workspace и модель
- [x] Cargo workspace с crates из `ARCHITECTURE.md` §2 (пустые там, где пока не нужны)
- [x] `core`: типы Batch / Source / Short / Template (минимальный: фон-blur + одно основное видео) с serde
- [x] `i18n`: Fluent, файлы `ru.ftl`/`en.ftl`, переключение языка
- [x] Пути XDG, `settings.toml` (чтение/запись с дефолтами)

- [x] Экран «Импорт»: выбор нескольких файлов (диалог + drag-and-drop), список пачки со статусами

- [x] Воспроизведение выбранного шортса в превью 9:16 (минимальный шаблон: blur-фон + видео по центру)

## Шаг 1.4 — Простой рендер
- [x] `render`: генерация `filter_complex` для минимального шаблона, H.264 (VAAPI или libx264 по `Capabilities`)
- [x] Папка вывода, базовое имя, нумерация `<name>_1.mp4`, политика конфликтов «продолжить нумерацию»

## Критерии приёмки
- Пользователь может вручную нарезать ролик на шортсы и получить файлы.
- Приложение запускается на Hyprland без ошибок, интерфейс на русском и английском.

## Передача дальше

### Шаг 1.1 (2026-11-12) — сделан
- Workspace в корне репо, `crates/*`; спайки исключены (`exclude = ["spikes"]`). Пакеты называются `sc-<имя>`
  (`sc-core`, `sc-i18n`…), бинарник — пакет `shortscutter` в `crates/app`. Имя `core` занято встроенным крейтом Rust.
- `sc-core`: `geometry` (`Rect` в долях, `Color` ↔ `#RRGGBB[AA]`), `template` (`Template::minimal()` — blur + 16:9 по центру,
  `validate()`, TOML с тегом `type`), `batch` (`Batch`/`Source`/`Short`/`OutputSettings`, id — UUID; `add_short`/`update_short`
  проверяют границы, длительность исходника и перекрытия; отклонённые шортсы перекрытиям не мешают), `paths` (XDG,
  `Paths::with_root` для тестов), `settings` (`#[serde(default)]` — недостающие поля из дефолтов, атомарная запись,
  битый файл → `settings.toml.bad` + дефолты).
- `sc-i18n`: `I18n::tr/tr_args`, `locales/{ru,en}.ftl` встроены `include_str!`; тест сверяет наборы ключей RU/EN;
  русские плюралы работают через CLDR (`one/few/many`). Изоляция направления выключена — egui рисует U+2068 как мусор.
- `shortscutter` (app): вкладки-заглушки, переключение языка в «Настройках» сразу сохраняет `settings.toml`.
- Проверено: `cargo test --workspace` (18 тестов), `cargo clippy` без предупреждений, окно на RU/EN в headless sway.

Неочевидное:
- egui/eframe 0.36: `App::ui(&mut self, ui, frame)` вместо `update(ctx)`, панели — `egui::Panel::top/bottom(...).show(ui, …)`.
- В headless sway eframe пишет `Failed to initialize arboard clipboard … X11` — безвредно (нет X11); на Hyprland проверить буфер обмена.
- `Settings::allow_overlaps` пока не используется моделью — `Batch` перекрытия запрещает всегда; подключить, когда появится UI настройки.
- clippy поставлен в тулчейн пользователя (`rustup component add clippy`).

### Шаг 1.2 (2026-11-12) — сделан
- `sc-media`: `probe()` — ffprobe JSON → `MediaInfo` (пропускает обложки `attached_pic`, учитывает поворот из
  `side_data_list`/`tags.rotate`, fps из `avg_frame_rate`, иначе `r_frame_rate`); `quick_hash()` — blake3 от размера и трёх
  кусков по 1 МиБ, формат `<размер hex>-<32 hex>`; `Capabilities::detect()` — версия, `/dev/dri/renderD*`, обязательные
  фильтры, пробное кодирование 3 кадров каждым кандидатом параллельно (~0.4 с), `encoder_for(codec, EncoderPref)`.
  Все внешние вызовы — через `process::run` с таймаутом и `stdin=null`.
- App: модули `jobs` (поток на задачу → mpsc → `request_repaint`) и `import`. Проверка ffmpeg в фоне при старте,
  итог в строке состояния и в «Настройках» (таблица кодировщиков ✔/✖). Импорт: диалог `rfd` (портал), drag-and-drop,

  содержимому. Ошибки исходника хранятся как i18n-ключ в `SourceStatus::Failed` (язык переключается без потерь).
  В `Settings` появилось `last_import_dir`.
- Проверено: 29 тестов (`sc-media` — 8 модульных + 2 на настоящем ffmpeg), clippy чистый, скриншот в headless sway:

  На ПК: h264/hevc_vaapi ✔, av1_vaapi ✖, все CPU-кодировщики ✔, фильтры все есть.

### Шаг 1.3 (2026-11-12) — сделан
- Новый крейт **`sc-mpv`** (`crates/mpv`): FFI к libmpv из спайка, без зависимости от egui (колбэк пробуждения — замыкание).
  Только асинхронные вызовы; события — `Event::{Property, FileLoaded, EndFile{error}, PlaybackRestart}`; сообщения mpv
  (warn и выше) идут в `log`, а не в терминал. `set_c_numeric_locale()` вызывается в `main`.
- **`sc-compositor`**: `gl::{Target, Blur}` из спайка (ошибки GL — `Result`, без паник) и `Compositor` — текстура кадра
  с мипмапами + размытый фон по `Template.background` (¼ холста, сигма 40 px холста 1080).
  Слои поверх фона рисует egui (`RectShape::with_texture`, скругление средствами egui).
- **`sc-core`**: `Rect::cover/sub/zoom_center`, `background_crop()` и `main_video_crop()` — общие формулы кропа для превью
  и будущего рендера (render и compositor друг от друга не зависят). `main_video_crop` подрезает кроп по центру под
  пропорции `dest`, поэтому не-16:9 исходник не растягивается — **рендер на шаге 1.4 должен использовать эти же функции**.
- App: `player.rs` (mpv + композитор, состояние только из событий, `pump` в начале кадра, `end_frame` → `report_swap`,
  `destroy` в `on_exit`), `timeline.rs` (виджет + `View` с тестами), `cut.rs` (вкладка «Нарезка»), `fmt.rs`.
  Если libmpv не поднялся — приложение работает, на «Нарезке» сообщение с причиной.
- «Нарезка»: слева ролики пачки, в центре холст 9:16, снизу кнопки, таймлайн и полоса шортсов.
  Клавиши: Пробел, I / O, Enter (шортс из отметок; без O — до текущей позиции), Del, Esc, ←/→ — кадр, Shift+←/→ — 5 с;
  **Ctrl+1…6 — вкладки**. Таймлайн: колесо — масштаб вокруг указателя (до 2 с на ширину), Shift+колесо — сдвиг,
  клик — точный seek, перетаскивание — по ключевым кадрам, отпускание — точный; края выбранного шортса тянутся
  (неверное положение — перекрытие — просто не применяется). При воспроизведении окно таймлайна листается за курсором.
- Выбор шортса = seek в его начало + `ab-loop` на его границы; ▶ играет его по кругу. Перемотка за пределы — снимает выбор.
  При уходе с вкладки «Нарезка» плеер ставится на паузу.
- Проверено: 34 теста, clippy чистый; в headless sway (GPU) — 1080p60 H.264 (1:50:50) и 4K HEVC: кадр, размытый фон,
  создание шортса с клавиатуры, петля, ошибка перекрытия, счётчик шортсов. Скриншоты не сохранялись в репо.

Неочевидное:
- **Автоматизация headless sway**: у seat нет устройств ввода (`capabilities: 0`), поэтому приложение не подписывается на
  клавиатуру и короткий `wtype` не доходит. Решение — держать виртуальную клавиатуру всё время: `wtype -s 300000 "" &`
  **до** запуска приложения, затем `wtype -M ctrl -k 2 -m ctrl` и т.п. Готовый скрипт — `tools/ui-run.sh`
  (`spikes/05-preview/headless.sh tools/ui-run.sh <видео> "key i; shot имя"`, скриншоты в `/tmp/sc13`). Мышь (`swaymsg seat … cursor`) так не работает —
  таймлайн мышью проверит пользователь.
- `＋` (полноширинный плюс) нет в шрифтах egui — квадратик. Символы для кнопок проверять скриншотом.
- `Frame::register_native_glow_texture` при каждой смене размера кадра регистрирует новый id, старый не освобождается
  (eframe не даёт API) — утечка одной записи на смену ролика, несущественно.
- egui 0.36: вложенные панели — тот же `Panel::left(...).show(ui, …)` внутри `CentralPanel`; `Button::selectable` для списков.

### Шаг 1.4 (2026-11-12) — сделан
- **`sc-render`** (зависит только от `sc-core`): `graph::build` — `filter_complex` по шаблону: `[0:v]format=yuv420p,split` →
  фон (`crop` по `background_crop` → ¼ холста → `gblur` с той же сигмой, что в превью (40 px холста 1080 / 4) →
  `lutyuv` — умножение на `1 − darken`, как `dim` в шейдере → `scale` на холст) или `color`; слои — `crop` по `main_video_crop`
  → `scale …:flags=lanczos` → (`alphamerge` с PGM-маской, если `corner_radius > 0`) → `overlay`; хвост `setsar=1` +
  `format=yuv420p` или `format=nv12,hwupload`. Маска скругления — `graph::mask_pgm` (SDF, сглаженный край), без PNG-зависимостей.
  `fps`/`resolution` из `OutputSettings` поддержаны (fps — в начале графа, разрешение — `scale` в хвосте).
- `job::RenderJob::run(cancel, progress)`: `-ss/-t` до `-i`, `-progress pipe:1 -stats_period 0.25`, пишет в `.<имя>.part`,
  после успеха — `rename`; при ошибке/отмене `.part` и временный каталог (маски) удаляются. Кодировщики: `h264_vaapi`/`hevc_vaapi`
  (VBR) и `libx264` veryfast / `libx265` fast; битрейт, maxrate ×1.5, bufsize ×2; HEVC с тегом `hvc1`. AV1/VP9/ProRes и webm —
  `UnsupportedEncoder/Container` до этапа 7.
- `naming::plan_outputs(batch)` — принятые шортсы по порядку исходников и времени; нумерация сквозная в пределах каталога;
  «продолжить» — после максимального `<имя>_N.<ext>`, «перезаписать» — с 1, **«спросить» пока как «продолжить»** (диалог — этап 7).
  Папка `None` — рядом с исходником.
- App: вкладка «Экспорт» (`export.rs`): папка (диалог `pick_folder` через портал / «рядом с исходником»), имя файлов с примером,
  выбранный кодировщик, список будущих файлов, кнопка «Рендер: N шортсов», два прогресс-бара (текущий и всего), «Отмена»,
  итоги ✔/✖; прогресс и в строке состояния. Рендер — последовательно в одном потоке (`jobs::Notifier` для многих сообщений).
  Папка и имя сохраняются в `settings.toml` (`output`) — следующая пачка начнёт с них.
- Пример без UI: `cargo run --release -p sc-render --example render_short -- <видео> <w> <h> <начало> <конец> <выход> [кодировщик]`.
- Проверено: 46 тестов (в `sc-render` 11 модульных + рендер и отмена на настоящем ffmpeg), clippy чистый.
  Twitch-VOD 1080p60: шортсы 30/45/20 с через `h264_vaapi` — 9.9/14.5/6.3 с (~19 с на минуту шортса), 1080×1920@60, AAC.
  В headless sway: рендер из UI, нумерация после существующего `тест_4.mp4` → `тест_5`, отмена на 12% — ни `.part`, ни файла.
  Кадр превью и кадр рендера в тот же момент: геометрия совпадает, отличие только в размытом фоне (PSNR 26.8 дБ).

Неочевидное:
- **Главы исходника** (у Twitch-VOD они есть) ffmpeg по умолчанию переносит в MP4 отдельной дорожкой `bin_data` —
  нужны `-map_chapters -1 -map_metadata -1`.
- Фон в превью уменьшается мипмапами, в ffmpeg — `scale` (bicubic), поэтому размытие чуть отличается; на глаз почти одинаково.
  Если понадобится точнее — `scale=…:flags=area` для уменьшения фона.
- У `lutyuv` есть константы `minval/maxval` — затемнение яркости `minval+(val-minval)*d` верно и для limited range.
- Повторное нажатие «Рендер» рендерит те же шортсы под новыми номерами (пометка «уже отрендерен» — этап 7).
- egui: фокус Tab доходит до кнопок — так автоматизирован запуск рендера в headless (10× Tab → «Рендер», после старта 7× Tab → «Отмена»).
  Каждый `wtype` в headless иногда теряется — шортсов создаётся меньше, чем задумано; на результат проверок не влияет.
