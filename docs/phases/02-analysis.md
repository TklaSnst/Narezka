# Этап 2 — Нарезка по смыслу ⭐

**Цель:** приложение само предлагает шортсы — законченные мысли ≤60 с (до ~120 с при необходимости),
а пользователь быстро проверяет и правит их.

**Читать перед началом:** `docs/ARCHITECTURE.md` §4; `docs/SPEC.md` §2; «Результаты» этапа 0 (модели, скорость, промпты в `spikes/prompts/`).

## Шаг 2.1 — Транскрипция
- [ ] `analysis`: извлечение аудио, запуск Whisper, слова с таймкодами
- [ ] Словарь терминов в настройках → initial prompt
- [ ] Кэш по хэшу файла, повторное открытие не запускает распознавание
- [ ] Фоновая задача с прогрессом и отменой; пакет анализируется по очереди
- [ ] Загрузка моделей при первом запуске с прогрессом (или указание готового файла)

## Шаг 2.2 — Структура текста
- [ ] Предложения и паузы (по таймкодам слов, `silencedetect` — доп. сигнал)
- [ ] Эмбеддинги предложений и кандидаты границ тем (TextTiling-подобный алгоритм)
- [ ] Тесты на сохранённом транскрипте тестового ролика

## Шаг 2.3 — LLM-нарезка
- [ ] Промпты в файлах ресурсов (перенести и доработать из `spikes/prompts/`)
- [ ] Проход 1: окна с перехлёстом → границы + зоны «интро/аутро/реклама», JSON-грамматика
- [ ] Слияние с границами из эмбеддингов, пометка «проверь» при расхождении
- [ ] Проход 2: оценка, причина, заголовок, ключевые слова для каждого кандидата
- [ ] Доводка: прилипание к паузам с отступом, проверка длительности, ужатие слишком длинных
- [ ] Выгрузка Whisper из VRAM перед загрузкой LLM
- [ ] Прогон на 2–3 роликах пользователя, итерация промптов вместе с ним

## Шаг 2.4 — Экран «Нарезка»
- [ ] Список кандидатов: оценка, длительность, заголовок, текст, пометки ⚠
- [ ] Принять / отклонить / разделить / объединить / добавить вручную
- [ ] Текст под таймлайном, клик по слову ставит in/out (прилипание к словам)
- [ ] Ручная разметка зон пропуска, перезапуск нарезки с их учётом
- [ ] Отклонённые и не попавшие куски серым на таймлайне
- [ ] Опция «разрешить перекрытия» (по умолчанию выключена)

## Критерии приёмки
- На роликах пользователя большинство предложенных шортсов — законченные мысли (оценивает пользователь).
- Границы не режут слова.
- Часовой ролик анализируется за разумное время (ориентир из этапа 0), интерфейс не зависает.
