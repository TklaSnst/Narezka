# Этап 3 — Внешний вид ⭐

**Цель:** полноценные шаблоны, редактируемые мышкой, с превью, близким к рендеру. После этого этапа — MVP.

**Читать перед началом:** `docs/ARCHITECTURE.md` §3 (Template), §5, §6; `docs/SPEC.md` §3; `docs/references/README.md` (и картинки).

## Шаг 3.1 — Модель шаблона и композитор
- [ ] Полная модель Template из `ARCHITECTURE.md` §3 (без субтитров и обложки — они позже)
- [ ] Фоны: blur (с затемнением и масштабом), цвет, градиент, картинка, видео (в цикле)
- [ ] Несколько слоёв MainVideo (для «Двух экранов»), скругление, рамка, тень — в шейдере
- [ ] Z-order слоёв

## Шаг 3.2 — Растеризатор и паритет с рендером
- [ ] `raster`: текстовые слои (шрифт, размер, цвет, обводка, тень, выравнивание), акцент `*…*` цветом и плашкой
- [ ] Слой «капсула с логотипом»
- [ ] Подстановки `{part}`, `{title}`
- [ ] `render`: полный граф шаблона (маски скругления, overlay растров, несколько кропов)
- [ ] Сравнение превью и рендера на всех встроенных шаблонах: кадр из превью vs кадр из файла

## Шаг 3.3 — Редактор мышкой
- [ ] Выделение слоя кликом, перемещение, ручки масштаба, перемещение области кропа внутри исходника
- [ ] Привязка к центру/краям/другим слоям, сетка
- [ ] Панель свойств выбранного слоя
- [ ] Оверлей безопасных зон YouTube Shorts + предупреждение, если слой в зоне перекрытия

## Шаг 3.4 — Шрифты
- [ ] Комплект свободных шрифтов с кириллицей: пиксельный, жирный гротеск, моноширинный (проверить лицензии — OFL)
- [ ] Выбор системных шрифтов, добавление своего файла

## Шаг 3.5 — Встроенные и свои шаблоны
- [ ] Шесть встроенных шаблонов по `docs/references/README.md`: Terminal, Размытие + заголовок, Два экрана,
      Мем-плашка, Полный кроп, Чистый фон + заголовок
- [ ] Terminal: параметры «затемнение размытия» и «граница видео» (нет / линия / тень)
- [ ] Сохранить как / дублировать / переименовать / удалить свой шаблон
- [ ] Выбор шаблона для пачки; локальные правки для отдельного шортса
- [ ] Показать пользователю шаблоны на его ролике, правки по отзыву

## Критерии приёмки (= MVP)
- Встроенные шаблоны визуально близки к референсам.
- Превью и рендер совпадают по положению элементов, текст — по пикселям.
- Свой шаблон создаётся и сохраняется без правки файлов руками.
