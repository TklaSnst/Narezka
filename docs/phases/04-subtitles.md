# Этап 4 — Субтитры

**Цель:** опциональные субтитры из транскрипции, три режима анимации, редактируемый стиль и текст.

**Читать перед началом:** `docs/ARCHITECTURE.md` §3 (слой Subtitles), §5, §6 (субтитры); `docs/references/README.md` (devops-short-alert).

## Шаг 4.1 — Стиль и превью
- [x] Слой Subtitles в шаблоне: шрифт, размер, цвет, цвет акцента, обводка, плашка, позиция мышкой, слов в строке
- [x] Разбиение слов шортса на строки/фразы
- [x] Режимы: статичный / подсветка текущего слова / проявление (несказанные серые или скрыты)
- [x] Отрисовка в превью по текущему времени
- [x] Подсветка ключевых слов: ручная (клик) и автоматическая (ключевые слова из LLM, этап 2)

## Шаг 4.2 — Рендер и правка
- [x] Субтитры в рендере — те же растры `sc_raster::subtitle_art`, что в превью (не ASS, см. DECISIONS 2026-11-15):
      последовательность состояний (фраза × слово) с длительностями → один вход ffmpeg (concat-демультиплексор
      картинок) → `overlay`; сдвиг таймкодов с учётом обложки и вставки — когда они появятся (этапы 5–6)
- [x] Список субтитров шортса: правка текста слова/фразы
- [x] Сравнение превью и рендера

## Критерии приёмки
- Три режима работают в превью и в рендере, синхронно с речью.
- Субтитры не попадают в безопасные зоны без предупреждения.

## Передача дальше

### Шаг 4.1 (2026-11-15)

Сделано:
- `sc-core::template`: слой `subtitles` — `rect`, `font`, `size`, `color` (сказанные/обычные), `active_color` + `active_mode`
  (текущее слово цветом или плашкой), `keyword_color`, `dim_color` (несказанные в «проявлении»; альфа 0 — скрыты, место остаётся),
  `mode = static | highlight | reveal`, `words_per_line` (1–10), `lines` (1–4), `uppercase`, `outline`, `shadow`, `plate`
  (подложка строк), `align`, `valign`. Проверки в `validate`, зоны Shorts — как у текста. `Template::has_subtitles`.
- `sc-core::subtitles`: `SubtitleTrack::new(слова, слов в строке, строк)` — предложения (знак конца или пауза ≥ 0.7 с) делятся на фразы
  **поровну** (5 слов при вместимости 4 → 3 + 2, без «висящего» слова), фраза — на строки поровну; фраза видна с первого слова до
  следующей фразы, но не дольше 0.6 с после последнего слова. `at(t)` → (фраза, сколько слов начато). Ключевые слова — `keyword_hits`:
  ключевые фразы нарезки LLM, сравнение без регистра/пунктуации, «ё» = «е», у слов от 4 букв — с другим окончанием
  («ошибка» ~ «ошибки», «сервер» ~ «серверов», но не «серверная»). Ручные пометки — `Short::subtitles: SubtitleEdits { toggled }`
  (начала слов в мс; пометка обратна автоматической), при объединении шортсов складываются.
- `sc-raster`: `text::draw_spans` — общий рисовальщик кусков текста, каждый своим цветом и плашкой, подложка строк; обводка куска
  прозрачна, как его цвет (скрытые слова без контура). `draw_text` теперь через него. `subtitle_art(слой, дорожка, фраза, начато)` —
  растр фразы в состоянии; раскладка одинакова во всех состояниях (проверено тестом), строки — без переноса, широкие ужимаются.
- Превью: `Player::set_subtitles(SubtitleInput)` — слова шортса или образец; отдельный поток `subtitle_worker` рисует текущее состояние
  и 4 следующих (упреждение при воспроизведении), кэш 48 растров; композитор получил **подмены** растра слоя (`set_overlay`) —
  `set_layers` их не трогает, пока новый растр не готов, показывается прошлый (при перетаскивании — растянутый).
  Растр фразы — медиана 2.4 мс, первый ~70 мс (загрузка шрифта), release.
- Слова: `app::subtitles` — слова шортса, выбранного в «Нарезке» (середина внутри шортса, как текст «Нарезки»), с ключевыми словами;
  на «Оформлении» без речи/шортса — образец «Так выглядят субтитры вашего шортса» (ключевое, текущее и несказанные видны сразу).
- «Оформление»: «+ Слой → Субтитры» (Montserrat ExtraBold, заглавные, 3 × 2, подсветка), панель свойств (режим, цвета, скрыть
  несказанные, раскладка, заглавные, подложка, выравнивание, обводка, тень). «Нарезка»: **правый клик** по слову выбранного шортса —
  ключевое слово вкл/выкл, ключевые подчёркнуты в тексте.
- Встроенный «Чистый фон + заголовок» получил субтитры «проявлением» (по devops-short-alert): 3 слова в строку, текущее — красным,
  несказанные — полупрозрачные. Тестовый шаблон `tools/templates/subtitles.toml` (подсветка плашкой, 2 строки, тень).
- `spikes/08-vptr`: команда `rclick X Y` (правая кнопка).
- Проверено: 123 теста, clippy чистый. Headless sway на CS-ролике: шортс 0:30–0:40 — подсветка идёт синхронно со словом под курсором
  в тексте «Нарезки»; «проявление» по словам; «Оформление» — образец без шортса, реальные субтитры с шортсом, выделение и перетаскивание
  слоя мышью; правый клик по «просто.» → подчёркнуто и жёлтое в субтитрах.

Не сделано / неочевидное:
- **Рендер субтитров не делает** — слой в экспорте пока пустой (`sc_raster::layer` для `Subtitles` → пусто). Это шаг 4.2.
- Решение для 4.2 (DECISIONS 2026-11-15): рендер — теми же растрами, а не ASS/libass. Состояний ~2–3 на секунду речи, растр ~2–3 мс —
  минута шортса ≈ 150 растров ≈ полсекунды. Растры лучше отдавать ffmpeg одним входом (не 150 `-i`).
- Подсветка текущего слова держится до начала следующего слова (в паузе внутри фразы не гаснет) — меньше мигания и состояний.
- Время слов — по токенам whisper (`Word::start`), DTW не используется (пользователь ещё не выбрал, п. 2 STATUS).
- В режиме «статичный» состояние фразы одно (`spoken = 0`) — растр на фразу.
- Ключевые слова нарезки (`Short::keywords`) у шортсов, нарезанных вручную, пусты — там только ручные пометки.
- Отмены у правого клика нет (повторный клик снимает).

Следующий шаг — 4.2: субтитры в рендере, список субтитров шортса с правкой текста, сравнение превью и рендера.

### Шаг 4.2 (2026-11-15)

Сделано:
- `sc-render::subtitles`: `sequence(слой, слова, start, end, холст)` — интервалы с одинаковой картинкой (границы — начала слов,
  начала/концы фраз, края шортса; соседние одинаковые склеиваются; у «статичного» — одна картинка на фразу), растры
  `subtitle_art` всех состояний, **общий охват** (обрезан холстом) — все картинки одного размера и в одной точке, картинка 0 —
  пустая. `ffconcat()` — список `file/duration`, последняя запись повторена (иначе concat теряет её длительность).
- Граф: вход `Input::Subtitles { layer }` в порядке слоёв (`-f concat -i inN.ffconcat`, картинки `inN-K.png`) → `overlay=x:y`
  без `shortest` (overlay держит последнюю картинку). `RenderJob::subtitles: Vec<SubWord>` — слова шортса (как в превью:
  `app::subtitles::short_words`, с правками и ключевыми). `sc-raster`: `Bitmap::to_png` (быстрое сжатие, почти прозрачный
  растр в PNG в десятки раз меньше PAM), `Bitmap::blit`.
- Скорость: CS-ролик, 10 с шортса с субтитрами (VAAPI) — 4.2 с вместо ~3.2 с без них; растры+PNG — доли секунды.
- Правка текста: `SubtitleEdits::texts` (слово речи → новый текст; несколько слов — время слова делится поровну; пусто — слово
  убрано), `apply`, `set_range_text` (новый текст фразы делится поровну между её словами речи; часть слова речи за краем фразы
  сохраняется; совпало с речью — правка снимается), `reset_texts`, `merge` (при объединении шортсов).
  Ключевые слова ищутся в исправленном тексте.
- «Нарезка»: под списком шортсов — «Субтитры шортса» выбранного: фразы так, как разложит шаблон шортса (нет слоя — 3 × 2
  с подсказкой), время фразы от начала шортса (клик — перемотка, текущая — жёлтым), поле текста (Enter/уход — сохранить,
  Esc — отмена), ↺ — вернуть речь.
- **Найдено и исправлено**: whisper даёт соседним словам одинаковое начало (353 из 5493 слов CS-ролика: «Перед» 28.90–28.91,
  «школой» 28.90–29.27; пара начало+конец тоже не уникальна). Ключ «начало в мс» из 4.1 склеивал такие слова — правый клик
  помечал оба, правка текста перетирала соседнее. Теперь `word_id(start, dup)` = мс + номер среди слов с тем же началом
  в битах 32+ (у первого — просто мс, старые пометки валидны); `app::subtitles::speech_ids` считает номер по всей речи, а не по
  куску шортса. У слов замены ключ «ключевое» — `id + (k << 48)`.
- Проверено: 129 тестов (в т.ч. рендер на настоящем ffmpeg: картинка меняется вместе со словами и пропадает в паузе), clippy
  чистый. Рендер CS-ролика: `spikes/out/10/` (`highlight.png` — `tools/templates/subtitles.toml`, `reveal.png` — «Чистый фон»),
  подсветка совпадает со словами по времени. Headless: правка фразы (+слово → фразы переразложились 4 + 4), Esc, ↺;
  превью и кадр рендера в один момент (29.483 с) — одна фраза, одно состояние, одно место.

Не сделано / неочевидное:
- Сдвиг таймкодов на обложку/вставку — когда они появятся (этапы 5–6): `sequence` получает [start, end) исходника,
  нужна будет добавка ко времени.
- Отмены у правки текста нет (↺ возвращает речь целиком у слов фразы). Правка привязана к словам речи: если шортс сдвинуть
  так, что слово выпало, его правка просто не видна.
- Пример `render_short` берёт слова из `SC_TRANSCRIPT` (без ключевых и правок) — для ручных сравнений.
- В headless `Ctrl+A` после `wtype` с кириллицей срабатывал как `Ctrl+1` (раскладка виртуальной клавиатуры) — в сценариях
  не использовать, ставить курсор `End`.
