# Этап 5 — Библиотека, баннеры, вставки

**Цель:** баннер Lumen VPN на всю пачку, рекламные вставки с паузой основного видео, библиотека ассетов
и «Сделать как в прошлый раз?».

**Читать перед началом:** `docs/SPEC.md` §4; `docs/ARCHITECTURE.md` §3 (Asset, Batch, Short), §6.

## Шаг 5.1 — Библиотека
- [x] `library`: импорт ассета (копия в библиотеку), типы, метаданные (размер, длительность, ориентация, альфа), теги
- [x] Вкладка «Библиотека»: сетка превью, поиск по тегам, удаление, переименование
- [x] История использования (`history.toml`) — модель и файл; записи появятся с баннером и вставками (5.2–5.3)

## Шаг 5.2 — Баннер
- [ ] Баннер пачки: выбор из библиотеки, позиция и размер мышкой (по умолчанию — BannerSlot шаблона)
- [ ] Форматы: PNG/JPG/WebP, GIF, видео с альфой (WebM VP9, MOV ProRes 4444) — в превью и рендере
- [ ] Опциональный текст рядом (промокод/ссылка) — текстовый слой, привязанный к баннеру
- [ ] Флаги «без баннера» на пачку и на шортс
- [ ] Диалог при новой пачке: «Сделать как в прошлый раз?» (шаблон, баннер, позиция, вставка, output)

## Шаг 5.3 — Вставки
- [ ] Маркер вставки на таймлайне шортса (прилипает к паузе между фразами)
- [ ] Автоопределение ориентации: вертикальная → весь экран; горизонтальная → в слот основного видео; ручное переопределение
- [ ] Настройка ассета «скрывать баннер во время вставки», запоминается
- [ ] Превью: пауза основного видео → вставка → продолжение
- [ ] Рендер: сегменты + `concat`, пересчёт длительности, предупреждение о превышении лимита
- [ ] Флаги «без вставки» на пачку и на шортс

## Критерии приёмки
- Пачка с баннером и вставками рендерится корректно, аудио не рассинхронизируется после вставки.
- Повторная пачка настраивается одним кликом «как в прошлый раз».

## Передача дальше

### Шаг 5.1 (2026-11-15)

Сделано:
- `sc-core::asset`: `Asset` (id, имя, тип, файл в библиотеке, `hash`, размер, время импорта, теги, `meta`, `hide_banner` для вставок),
  `AssetKind` (баннер/вставка/картинка/фон/шрифт), `AssetMeta` (размер с учётом поворота, длительность — `None` у картинки, fps,
  альфа, звук, кодек, имя шрифта), `orientation()` (±10 % — квадрат), `suggest_kind` (шрифт; альфа или GIF → баннер; видео → вставка;
  иначе картинка). Поиск `Asset::matches`: каждое слово — в имени или теге, без регистра, «ё» = «е»; `#слово` — только тег, с начала.
  `parse_tags`: через запятую/`#`, нижний регистр, **пробелы внутри тега → `-`** (запрос делится по пробелам — тег с пробелом ломал
  чип-фильтр). `History` / `Usage { asset, role, at, rect? }`: `record` (лимит 500), `summary`, `last(role)`, `forget`.
- `sc-media::asset`: `probe_asset` (картинка = демультиплексор `image2`/`*_pipe`; GIF из одного кадра — картинка; альфа — по pix_fmt
  `yuva*`/`gbrap*`/`rgba`… или тегу `ALPHA_MODE=1` у VP9 — у него pix_fmt `yuv420p`), `thumbnail` (PNG RGBA ≤320 px, кадр на трети
  видео, не дальше 1 с; VP9 с альфой — через декодер `libvpx-vp9`, иначе прозрачность теряется; нет libvpx — повтор без него).
- `sc-library`: `stage` (хэш → копия `<id>.<ext>` через временный файл → ffprobe → миниатюра `thumbs/<id>.png`; битый файл копию
  не оставляет; шрифт без ffprobe) и `Library` (`library.toml`, `add` с отсевом повтора по хэшу, `search`, `tags`, `update`, `rename`,
  `delete` с файлом и миниатюрой; испорченный индекс → `.bad`), `load_history`/`save_history`. Пример
  `cargo run -p sc-library --example import -- <каталог> <файлы…>` — наполнить библиотеку без интерфейса.
- Вкладка «Библиотека»: «Добавить файлы…» (портал, несколько файлов; на X11 — ещё и перетаскивание в окно на этой вкладке),
  импорт в фоне по файлу (шрифт сразу подключается через `sc_raster::fonts::install_font`, имя — в `meta.font`); повтор — сообщение
  и выбор уже имеющегося. Фильтр по типу (с числом), поиск, чипы тегов (клик — добавить/убрать `#тег` в запросе). Сетка карточек:
  миниатюра с шахматкой под прозрачным, ▶ у видео/GIF, «Аа» у шрифта, ⚠ если файл пропал. Справа: превью, имя и теги
  (сохраняются по Enter/уходу фокуса), тип (шрифт не меняется и другим не назначается), у вставки — «Скрывать баннер во время
  вставки», сведения (формат, размер и ориентация, длительность и fps, прозрачность, звук, размер файла, дата, «использован N раз»),
  удаление с подтверждением (чистит и историю), «Открыть папку».
- Проверено: 140 тестов (в т.ч. импорт настоящих PNG с альфой, MP4 со звуком, WebM VP9 с альфой, ProRes 4444, GIF, битого файла),
  clippy чистый. Headless sway на временной библиотеке (`XDG_DATA_HOME=/tmp/scxdg`): сетка, выбор, теги, переименование, чип-фильтр
  вкл/выкл, смена типа, удаление — файлы и запись пропадают.

Не сделано / неочевидное:
- Диалог «Добавить файлы…» в headless не проверить (портал) — путь тот же `stage`, что в тестах; проверка — за пользователем.
- В headless не набирается кириллица и `#` (раскладка виртуальной клавиатуры wtype, `non-xkb compatible keymap`) — латиница работает.
- Шрифт хранится дважды: копия в библиотеке и копия в `fonts/` (её грузит растеризатор при запуске). Удаление шрифта из библиотеки
  копию в `fonts/` не трогает — шаблоны с этим шрифтом не ломаются.
- История пока только читается (в карточке «ещё не использовался»); записывать будут баннер (5.2) и вставки (5.3); туда же в 5.2 —
  раздел «как в прошлый раз» в `history.toml`.
- Слои «Картинка», капсула и фоны шаблона по-прежнему выбирают файл диалогом по пути, а не из библиотеки — выбор из библиотеки
  удобно добавить вместе с баннером (5.2).
- Даты — по местному времени (`localtime_r`).
