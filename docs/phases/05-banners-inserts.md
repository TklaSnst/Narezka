# Этап 5 — Библиотека, баннеры, вставки

**Цель:** баннер Lumen VPN на всю пачку, рекламные вставки с паузой основного видео, библиотека ассетов
и «Сделать как в прошлый раз?».

**Читать перед началом:** `docs/SPEC.md` §4; `docs/ARCHITECTURE.md` §3 (Asset, Batch, Short), §6.

## Шаг 5.1 — Библиотека
- [x] `library`: импорт ассета (копия в библиотеку), типы, метаданные (размер, длительность, ориентация, альфа), теги
- [x] Вкладка «Библиотека»: сетка превью, поиск по тегам, удаление, переименование
- [x] История использования (`history.toml`) — модель и файл; записи появятся с баннером и вставками (5.2–5.3)

## Шаг 5.2 — Баннер
- [x] Баннер пачки: выбор из библиотеки, позиция и размер мышкой (по умолчанию — BannerSlot шаблона)
- [x] Форматы: PNG/JPG/WebP, GIF, видео с альфой (WebM VP9, MOV ProRes 4444) — в превью и рендере
- [x] Опциональный текст рядом (промокод/ссылка) — текстовый слой, привязанный к баннеру
- [x] Флаги «без баннера» на пачку и на шортс
- [x] Диалог при новой пачке: «Сделать как в прошлый раз?» (шаблон, баннер, позиция, вставка, output) — вставка добавится в 5.3

## Шаг 5.3 — Вставки
- [ ] Маркер вставки на таймлайне шортса (прилипает к паузе между фразами)
- [ ] Автоопределение ориентации: вертикальная → весь экран; горизонтальная → в слот основного видео; ручное переопределение
- [ ] Настройка ассета «скрывать баннер во время вставки», запоминается
- [ ] Превью: пауза основного видео → вставка → продолжение
- [ ] Рендер: сегменты + `concat`, пересчёт длительности, предупреждение о превышении лимита
- [ ] Флаги «без вставки» на пачку и на шортс

## Критерии приёмки
- Пачка с баннером и вставками рендерится корректно, аудио не рассинхронизируется после вставки.
- Повторная пачка настраивается одним кликом «как в прошлый раз».

  `AssetKind` (баннер/вставка/картинка/фон/шрифт), `AssetMeta` (размер с учётом поворота, длительность — `None` у картинки, fps,
  альфа, звук, кодек, имя шрифта), `orientation()` (±10 % — квадрат), `suggest_kind` (шрифт; альфа или GIF → баннер; видео → вставка;
  иначе картинка). Поиск `Asset::matches`: каждое слово — в имени или теге, без регистра, «ё» = «е»; `#слово` — только тег, с начала.
  `parse_tags`: через запятую/`#`, нижний регистр, **пробелы внутри тега → `-`** (запрос делится по пробелам — тег с пробелом ломал

  `cargo run -p sc-library --example import -- <каталог> <файлы…>` — наполнить библиотеку без интерфейса.
- Вкладка «Библиотека»: «Добавить файлы…» (портал, несколько файлов; на X11 — ещё и перетаскивание в окно на этой вкладке),

  и выбор уже имеющегося. Фильтр по типу (с числом), поиск, чипы тегов (клик — добавить/убрать `#тег` в запросе). Сетка карточек:

Не сделано / неочевидное:
- Диалог «Добавить файлы…» в headless не проверить (портал) — путь тот же `stage`, что в тестах; проверка — за пользователем.

- Даты — по местному времени (`localtime_r`).

### Шаг 5.2 (2026-11-15)

Сделано:
- Модель (`sc-core::banner`): `Batch::banner: Option<Banner {asset, text: Option<BannerText>}>` (`None` — пачка без баннера),
  `Short::no_banner`, `Batch::banner_for(id)`. `BannerText` — содержимое (`*акцент*`), сторона (снизу/сверху/слева/справа),
  шрифт, кегль, цвет, акцент, обводка; прямоугольник текста считается от вписанной картинки и обрезается краем холста.
- **Положение баннера = рамка `BannerSlot` шаблона** (см. DECISIONS): двигается мышью как любой слой, хранится в шаблоне пачки
  (или локальном шаблоне шортса). При выборе баннера, если рамки нет, она добавляется в шаблон пачки (шаг отмены).
- `Template::with_banner(Option<&BannerArt>)`: первый `BannerSlot` → `Layer::Image` (PNG/JPEG/WebP) или новый
  `Layer::Clip {rect, path, width, height, decoder}` (GIF, видео, прочие картинки — через ffmpeg); текст — `Layer::Text` в конце.
  `BannerArt::new` берёт из ассета размер, «анимация ли», декодер с альфой (`alpha_decoder`: VP9 → `libvpx-vp9`, VP8 → `libvpx`).
  Порядок применения: `with_banner` → `with_vars` (в тексте баннера работают `{part}`/`{title}`).
- Рендер: `Input::Clip` — `-stream_loop -1 [-c:v libvpx-vp9] -i файл`, цепочка `fps,scale(вписать как картинку),format=yuva420p`
  → `overlay … shortest=1`. Геометрия — `sc_raster::clip_rect_px`/`fit_px` (те же, что у картинки).
- Превью (`player.rs`, `pump_clips`): кадры `sc_media::decode_frames` (rawvideo RGBA, 30 к/с, ≤160 МБ / ≤600 кадров, холст ≤720 px)
  в фоновом потоке, по одной раскадровке за раз (пока рамку тянут — растягивается прежний кадр); кадр = (время − начало
  петли шортса) × 30 по модулю — так же, как цикл в рендере. Кладётся подменой растра слоя (`set_overlay`), «нарисован для»
  прямоугольника в масштабе — композитор растягивает до места слоя.
- Интерфейс: «Оформление» → слой «Место под баннер» → раздел «Баннер пачки»: карточки баннеров и картинок библиотеки
  (баннеры и недавние — первыми), «Без баннера», «Открыть библиотеку», «Текст рядом» (текст, где, кегль, цвета, обводка, шрифт
  и «Свой шрифт…»), «Этот шортс — без баннера». Над рамкой с баннером — только тонкий контур. «Библиотека» → «Сделать баннером
  пачки». «Экспорт» — предупреждение, если ассет баннера пропал.
- При старте рендера: запись в историю (баннер с прямоугольником рамки) и `History::last_batch = BatchPreset` (шаблон, ссылка,
  баннер, вывод). При запуске приложения, если прошлое есть (и шаблон не из `SC_TEMPLATE`), — окно «Сделать как в прошлый раз?»
  (шаблон, баннер, папка) с «Да / Нет».
- Проверено: 146 тестов (новые: `with_banner`, текст рядом, `fit_rect`, пресет в TOML, граф с `Clip`, `decode_frames` с альфой,
  рендер на настоящем ffmpeg — PNG с полупрозрачностью и текстом, VP9 с альфой по кругу в такт выводу). Clippy чистый.
  Headless sway: выбор PNG и WebM-баннера, текст с акцентом в превью, анимация играет, рамка тянется вместе с баннером;
  рендер из интерфейса на VAAPI с анимированным баннером и текстом (кадры 1 с и 3 с совпадают — цикл 2 с); при следующем
  запуске — окно «как в прошлый раз», «Да» возвращает баннер и текст.

Не сделано / неочевидное:
- Встроенные шаблоны с рамкой баннера: пока только `terminal`; в остальных рамка появится при выборе баннера (по умолчанию —
  `DEFAULT_BANNER_RECT`, 0.1/0.62/0.8×0.1). Возможно, стоит добавить рамки во все встроенные шаблоны по референсам.
- Нет libvpx в ffmpeg → рендер WebM-баннера с альфой упадёт (превью повторит без декодера, без прозрачности). У пользователя libvpx есть.
- Выбор баннера и текст баннера не входят в отмену «Оформления» (там только шаблон); добавление рамки — входит.
- Анимация длиннее ~5–20 с (зависит от размера) в превью зациклится раньше, чем в рендере (лимит памяти раскадровки).
- В превью без выбранного шортса время анимации — время исходника (не важно для вида).
- `Layer::Clip` в шаблонах пользователь сам не создаёт (нет в «+ Слой») — только через баннер; при желании можно открыть
  его для GIF-картинок шаблона.
- В headless не набрать кириллицу — текст баннера проверен латиницей.
