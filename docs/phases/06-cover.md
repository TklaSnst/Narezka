# Этап 6 — Обложка-кадр

**Цель:** выбранный кадр (с надписями) стоит первым кадром шортса, чтобы YouTube взял его как превью.

**Читать перед началом:** `docs/SPEC.md` §5; `docs/ARCHITECTURE.md` §3 (Short.cover), §6.

## Шаг 6.1
- [ ] Выбор кадра: из шортса, из любого места исходника, или картинка из библиотеки
- [ ] Кадр рисуется в шаблоне шортса; мини-редактор поверх (тексты, изображения — те же типы слоёв)
- [ ] Стили обложек сохраняются как шаблоны обложек
- [ ] Длительность в кадрах (настраивается), звук — тишина (опция «звук сразу»)
- [ ] Рендер: сегмент-обложка в начале `concat`, субтитры и маркер вставки сдвигаются
- [ ] Эксперимент с пользователем: минимальная длительность, при которой YouTube стабильно берёт кадр → значение по умолчанию в `DECISIONS.md`

## Критерии приёмки
- После загрузки на YouTube превью шортса — выбранный кадр.
