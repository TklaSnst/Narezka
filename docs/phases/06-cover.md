# Этап 6 — Обложка-кадр

**Цель:** выбранный кадр (с надписями) стоит первым кадром шортса, чтобы YouTube взял его как превью.

**Читать перед началом:** `docs/SPEC.md` §5; `docs/ARCHITECTURE.md` §3 (Short.cover), §6.

## Шаг 6.1
- [x] Выбор кадра: из шортса, из любого места исходника, или картинка из библиотеки
- [x] Кадр рисуется в шаблоне шортса; мини-редактор поверх (тексты, изображения — те же типы слоёв)
- [x] Стили обложек сохраняются как шаблоны обложек
- [x] Длительность в кадрах (настраивается), звук — тишина (опция «звук сразу»)
- [x] Рендер: сегмент-обложка в начале `concat`, субтитры и маркер вставки сдвигаются
- [ ] Эксперимент с пользователем: минимальная длительность, при которой YouTube стабильно берёт кадр → значение по умолчанию в `DECISIONS.md`
  (пока 6 кадров — 0.1 с при 60 к/с; ждёт загрузок пользователя)

## Критерии приёмки
- После загрузки на YouTube превью шортса — выбранный кадр.

## Передача дальше

**Сделано (2026-11-15, шаг 6.1):**
- Модель: `sc-core::cover` — `Cover { source: Frame{t} | Image{asset}, template, frames, sound_now }` в `Short::cover`;
  обложка — **свой полный шаблон** (копия шаблона шортса + слои стиля), правится тем же редактором «Оформления».
  Встроенные стили (`plain`, `big-title`, `top-title`) — TOML-слои поверх шаблона шортса (`builtin_style`, субтитры
  убираются); свои стили — целые шаблоны через `UserTemplates` в `~/.local/share/shortscutter/cover-styles`.
  `Settings::cover_frames` — длительность новых обложек (запоминается при правке).
- Картинка из библиотеки встаёт **на место кадра видео** (в слои видео и размытый фон) — любой шаблон работает с обоими
  источниками. Превью: `Player::set_still` → `Compositor::upload_video` (картинка в текстуру кадра вместо mpv).
- Редактор: цель правки `design::Target { Batch, Short, Cover }` (вместо `design.short`), `Snapshot::Cover` — отмена
  общая. Блок «Обложка шортса» над слоями (`app/src/cover.rs`): вкл/выкл, «✏ Править обложку», кадр видео (слайдер
  по всему исходнику, ±кадр, начало шортса, 📍 «кадр превью»), картинка (список картинок библиотеки), длительность
  в кадрах (≈ мс), «звук сразу», стиль + «Сохранить стиль как…» / «Удалить стиль», «Обложки всем принятым».
- Рендер: предварительный проход ffmpeg рисует кадр обложки по её шаблону в `cover.png` (размер холста; кадр — `-ss t`,
  картинка — `-loop 1`); основной граф после всех слоёв: `[cover][база]concat` (с тишиной `anullsrc` перед звуком,
  в том числе перед склейкой звука вставки) или при «звук сразу» — `overlay … eof_action=pass` поверх первых кадров.
  Субтитры и вставка живут во времени шортса **до** concat — сдвигать их не нужно. `final_duration` учитывает обложку
  (предупреждение > 3 мин).
- Тесты: 160 (было 156): стили/длительность/TOML в `sc-core`, `renders_covers` на настоящем ffmpeg — кадр из другого места
  исходника, картинка + «звук сразу», обложка + вставка (длины видео и звука, тишина на обложке и во время вставки).
- Headless-проверка UI (sway, мышь `vptr`): включение обложки, перемотка слайдером к 57:30 (вне шортса), выключение правки.

**Не сделано / ограничения:**
- Эксперимент с YouTube (минимальная длительность) — за пользователем; по умолчанию 6 кадров.
- Обложка — копия шаблона: если потом поменять шаблон пачки/шортса, существующая обложка не меняется (выбрать стиль заново).
- В «Нарезке» при воспроизведении обложка не показывается (она видна на «Оформлении» и в рендере).
- Картинка-источник в превью в headless не проверена (библиотека пустая, импорт — через портал).
- Обложка не входит в «Сделать как в прошлый раз» (стиль для новых обложек помнится только до перезапуска).

**Неочевидное:**
- Fluent срезает пробелы в начале значения — суффикс с пробелом пишется `{" "}кадр.`.
- В графе без видео и размытия (`split=0` недопустим) исходник уходит в `nullsink`.
- Пока показана картинка, у mpv всё равно забирается флаг нового кадра; при возврате к видео — точный seek, чтобы mpv перерисовал кадр.
