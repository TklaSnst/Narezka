# Этап 7 — Output и очередь

**Цель:** все форматы и настройки качества, пакетная очередь рендера, уведомления, метаданные.

**Читать перед началом:** `docs/SPEC.md` §6; `docs/ARCHITECTURE.md` §6; «Результаты» шага 0.4 (скорость кодеков).

## Шаг 7.1 — Форматы и качество
- [ ] Контейнеры/кодеки: MP4 (H.264, H.265, AV1), WebM (VP9, AV1), MOV (ProRes 422 Proxy/LT/Std/HQ, 4444)
- [ ] Недоступные по `Capabilities` — неактивны с подсказкой
- [ ] Пресеты «Высокое / Сбалансированное (по умолчанию) / Быстрое» для каждого кодека
- [ ] Расширенные настройки: CRF/QP, битрейт, GPU/CPU, профиль, GOP, аудиокодек/битрейт; сохранение своих пресетов
- [ ] Разрешение (1080×1920 по умолчанию, 720×1280, 1440×2560, своё), fps (как в исходнике / 30 / 60)

## Шаг 7.2 — Очередь
- [ ] Очередь всех принятых шортсов пачки (по всем исходникам), N параллельных задач (по умолчанию 2)
- [ ] Прогресс по каждому файлу и общий, пауза, отмена, удаление недописанных файлов
- [ ] Ошибка одного файла не останавливает остальные; лог ошибки доступен из UI
- [ ] Политика конфликтов имён: продолжить нумерацию (по умолчанию) / спросить / перезаписать
- [ ] Нумерация сквозная по пачке, начиная с 1

## Шаг 7.3 — Уведомления и метаданные
- [ ] Уведомление по окончании (D-Bus), опция
- [ ] Экспорт `name_n.txt`: заголовок, таймкоды в исходнике, текст, хэштеги (опция, по умолчанию выключена)

## Критерии приёмки
- Пачка из нескольких роликов рендерится одной кнопкой во всех поддерживаемых форматах.
