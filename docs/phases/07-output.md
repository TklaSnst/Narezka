## Шаг 7.1 — Форматы и качество
- [x] Контейнеры/кодеки: MP4 (H.264, H.265, AV1), WebM (VP9, AV1), MOV (ProRes 422 Proxy/LT/Std/HQ, 4444)
- [x] Недоступные по `Capabilities` — неактивны с подсказкой
- [x] Пресеты «Высокое / Сбалансированное (по умолчанию) / Быстрое» для каждого кодека

## Шаг 7.2 — Очередь

**Не сделано / ограничения:**
- GPU-рендер через приложение со всеми форматами не гонялся (интеграционный тест — только CPU-кодировщики).
- ProRes 4444 — без альфы (вывод непрозрачный); 10 бит только в хвосте графа, внутри — 8-битный yuv420p.
- Скорость у VAAPI не настраивается (неактивна), пресеты GPU отличаются только битрейтом.

**Неочевидное:**
- VP9 `good` в 4 раза медленнее `realtime` при том же SSIM (10 с 1080×1920@60, CRF 32: good/4 — 31 с, realtime/5 — 9 с,
  SSIM 0.9875 / 0.9879) → «медленно» = good/4, остальное — realtime 5/7/8. svt-av1: preset 6 — 1.5×, 8 — 0.9×, 10 — 0.5× реального времени.
- ffprobe показывает ProRes 4444 как `yuv444p12le` — так сообщает декодер, кодировали 10 бит.
- При смене кодека «Своё» сбрасывается на «Сбалансированное»: CRF 32 у VP9 и x264 — разное качество.
- Headless-тесты UI пишут в настоящий `~/.config/shortscutter/settings.toml` — после проверки вернуть как было.
- wtype в headless не вводит кириллицу (имя пресета в проверке — латиницей).
