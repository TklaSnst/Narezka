# Этап 8 — Полировка и пакет

**Цель:** приложение готово к ежедневному использованию и ставится одним `.deb`.

**Читать перед началом:** `docs/STATUS.md`, открытые замечания в «Передаче дальше» всех этапов.

## Шаг 8.1 — Полировка
- [ ] Проход по всем экранам: тексты RU/EN полные, ошибки понятные, тёмная тема ровная
- [ ] Окна диалогов с понятным `class`/`title`; пример floating-правил Hyprland в README
- [ ] Обработка крайних случаев: файл без звука, VFR-видео, повёрнутое видео (rotation metadata), очень короткий исходник

## Шаг 8.2 — Пакет
- [ ] `cargo-deb`: зависимости (ffmpeg, libmpv, mesa-va-drivers, mesa-vulkan-drivers), `.desktop`-файл, иконка
- [ ] Модели не входят в пакет — скачиваются при первом запуске
- [ ] Установка на чистую Ubuntu (VM или контейнер) и запуск

## Шаг 8.3 — Совместимость
- [ ] Проверка на одном не-Debian дистрибутиве (Arch или Fedora) из исходников
- [ ] README: установка, сборка из исходников, требования

## Критерии приёмки
- Пользователь ставит `.deb` и проходит полный цикл: импорт → нарезка → оформление → рендер.
