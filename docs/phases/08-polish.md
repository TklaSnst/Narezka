### Шаг 8.1 (2026-11-19) — выполнен по коду

**Крайние случаи** — тест `crates/render/tests/edge_sources.rs` (исходник через `sc_media::probe`, как в приложении, рендер
libx264): без звука, VFR-mkv, поворот 90°, исходник 0.4 с. Нашлись и исправлены три ошибки:
- **VFR протекал в шортс**: с размытым фоном база графа идёт по меткам исходника — у VFR-mkv выходило 100 кадров за 3 с
  при заявленных 60 к/с. Теперь на входе графа всегда `fps=<частота вывода>` (раньше — только если частота задана явно).
  В `probe` средняя частота подтягивается к ближайшей стандартной в пределах 2 % (`snap_rate`: 30.4 → 30, 29.87 → 29.97).
- **Превью повёрнутого видео не совпадало с рендером**: в render API mpv поворачивает сам VO, и `dwidth/dheight` —
  «лежачие» (1280×720 при `video-out-params/rotate` = 270; с `--vo=null` mpv вставляет фильтр, и там уже 720×1280 —
  поэтому раньше не замечали). Текстура кадра была лежачей, кадр вписывался в слот с полями. Теперь `player::Frame`
  учитывает поворот — у основного плеера, видео-фона и вставки.
- **Ролик без речи** (тишина, музыка, пара секунд): нарезка грузила LLM на 6 ГБ ради пустого текста. Теперь при нуле
  предложений — сразу пустой итог (и в кэш), модели не нужны. В «Импорте» — «Речь не найдена — только ручная нарезка»
  вместо «Распознано: 0 слов · 0 кандидатов»; в «Нарезке» — свои подсказки вместо «Все кандидаты убраны» и
  «Текст появится после распознавания».
- Файл без звука (дорожки нет) и очень короткий исходник уже работали: анализ — «Нет звука — только ручная нарезка»,
  рендер без аудиодорожки; конец шортса обрезается по длительности.

**Диалоги.** Диалоги портала (rfd) теперь с родителем — окном приложения (`App::file_dialog`, сырые ручки из
`CreationContext`, xdg-foreign): портал открывает их как дочерние. Класс у них — портала (`xdg-desktop-portal-gtk`),
поэтому заголовок всегда «ShortsCutter — …» — по нему ловит правило Hyprland. Пример правил (0.53+ и `windowrulev2`) — в README.
Окна внутри egui («Лог», модальные) — часть главного окна (`app_id` `shortscutter`).

**Тексты.** Паритет RU/EN уже под тестом; сверка ключей в коде с `.ftl` — пропусков нет (совпадения по шаблону — id виджетов),
неиспользуемый `placeholder-not-ready` удалён. Строк интерфейса мимо i18n нет; ошибки — «локализованная фраза + техническая
деталь» (stderr ffmpeg и т. п. не переводятся). Скриншоты всех вкладок в headless sway — тёмная тема ровная.

Проверено: 180 тестов, clippy чистый; headless sway — статусы «нет речи», превью повёрнутого ролика = рендер (Terminal),
клик «Добавить видео…» с родителем не вешает интерфейс.

**Не сделано / неочевидное:**
- Диалог с родителем на настоящем Hyprland не проверен (в headless портал не показывает окно) — п. 27 STATUS.
- Открытые замечания прошлых этапов почти все — приёмка пользователем (п. 1–26 STATUS); по коду из них в 8.1 ничего не
  брали. Остаются как известные ограничения: превью анимации баннера длиннее ~5–20 с зацикливается раньше рендера; во время
  вставки «в слот» фон и остальные слои видео стоят на замершем кадре; ProRes 4444 без альфы; повторить упавший файл очереди
  нельзя; обложка не входит в «как в прошлый раз».
- У пользователя на ПК модель нарезки — висящая ссылка (`~/.cache/shortscutter/models/Qwen3.5-9B-UD-Q4_K_XL.gguf` →
  удалённый `~/work/local-models`). Приложение видит её как отсутствующую и предлагает «Скачать модели (6.0 ГБ)»;
  загрузка пишет `.part` и `rename` заменяет саму ссылку.
- Для пакета (8.2): whisper.cpp собирается с `GGML_NATIVE` (под этот CPU) — выключить (заметка этапа 2).

### Шаг 8.2 (2026-11-19) — выполнен по коду

**Сборка пакета:** `./tools/package-deb.sh` → `target/debian/shortscutter_0.1.0-1_amd64.deb` (20 МБ). Нужен `cargo-deb`
(`cargo install cargo-deb --locked`, на ПК стоит 3.8.0). Скрипт: `SC_PORTABLE=1 cargo build --profile dist`, копирует
`llama-server` из `OUT_DIR` sc-llama в `target/dist/`, затем `cargo deb --profile dist --no-build`. Метаданные — в
`crates/app/Cargo.toml` (`[package.metadata.deb]`), `.desktop` и иконка (SVG) — в `packaging/`.

**Состав:** `/usr/bin/shortscutter`, `/usr/lib/shortscutter/llama-server` (не в `/usr/bin` — там может быть
`llama-server` из пакета llama.cpp), `shortscutter.desktop` (`StartupWMClass=shortscutter`, MimeType видео — «Открыть с
помощью» передаёт файлы аргументами), иконка в `hicolor/scalable`. `sc_llama::server_binary` теперь ищет и
`<каталог exe>/../lib/shortscutter/llama-server`.
Depends: `$auto` (libmpv2, libvulkan1, libstdc++6, libc6) + `ffmpeg`, `xdg-desktop-portal`; Recommends:
`mesa-va-drivers`, `mesa-vulkan-drivers`, портал-бэкенд (на NVIDIA mesa не нужна — поэтому не Depends).

**CPU:** профиль `dist` (release + thin LTO + strip) — отдельный `target/dist`, где whisper.cpp и llama.cpp собраны с
`SC_PORTABLE=1`: `GGML_NATIVE=OFF`, AVX/AVX2/FMA/F16C/BMI2 (x86-64-v3). Обычные `cargo build/run` по-прежнему с
`GGML_NATIVE` — переключение переменной не пересобирает их кэш. Проверено: `target/dist/examples/transcribe` на
`media/twitch-1min.wav` — 101 слово, 7.9 с (Vulkan, RX 6600), как и раньше.

**Модели** в пакет не входят: на первом запуске «Импорт» показывает «Скачать модели (8.2 ГБ)» / «Указать файл модели…»
(механизм был с этапа 2).

**Чистая Ubuntu:** контейнер `ubuntu:26.04` на VPS (docker; на ПК нет ни docker/podman, ни непривилегированных userns —
AppArmor). `apt install ./shortscutter.deb` ставит всё сам, у бинарников нет ненайденных библиотек, `llama-server
--version` работает, `desktop-file-validate` чист. Запуск под пользователем в headless sway (pixman, без GPU): окно
открывается, «GPU: нет», кодеры CPU (libx264/x265/svtav1/vpx/prores) найдены, предложение скачать модели; каталоги
`~/.config|.local/share|.cache/shortscutter` созданы. Сценарий — вне репо (`/root/work/debtest/test.sh` на VPS).

**Не сделано / неочевидное:**
- Полный цикл из пакета (импорт → нарезка → оформление → рендер) на настоящем GPU — приёмка пользователем (п. 28 STATUS).
- CPU без AVX2 (до ~2013–2015) упадёт с SIGILL в ggml даже при расчёте на GPU. Варианты под разные CPU
  (`GGML_CPU_ALL_VARIANTS`) требуют `GGML_BACKEND_DL` — динамические бэкенды, отказались ради простоты.
- Иконка только SVG (на ПК нет rsvg/inkscape для PNG); лаунчеры Hyprland (wofi, fuzzel, rofi) и GNOME SVG понимают.
- В бинарник зашит путь `SC_LLAMA_SERVER_BUILT` из машины сборки — это последний запасной путь, в пакете не используется.
- Версия пакета `0.1.0-1` — из `workspace.package.version`.

### Шаг 8.3 (2026-11-19) — выполнен по коду

**Arch Linux из исходников** — rootfs `archlinux-bootstrap` на ПК, вход через `bwrap` с uid 0 в пространстве имён
пользователя (`~/work/distrotest/arch.sh`, вне репо; docker на ПК нет, а на VPS мало памяти для ggml-vulkan рядом с продом).
pacman в bwrap работает, если в `pacman.conf` закомментировать `DownloadUser` и `CheckSpace`; хуки с systemd падают —
на сборку не влияет. Корень rootfs после установки `filesystem` — 555, сборку класть в `/root/build`.
GPU пробрасывается (`--dev-bind /dev/dri`, `--ro-bind /sys`) — в Arch видны RADV и VAAPI с настоящей RX 6600.

Пакеты: `base-devel git cmake clang rustup vulkan-headers vulkan-icd-loader shaderc spirv-headers mpv ffmpeg`
(+ `vulkan-radeon` для AMD). Rust 1.100 (rustup), Mesa 26.2.7, ffmpeg n9.0.2.
- **Нужен `spirv-headers`**: свежий llama.cpp (ggml-vulkan) ищет `SPIRV-HeadersConfig.cmake` — без пакета cmake падает.
  На Ubuntu он был поставлен раньше, поэтому не замечали; в README добавлен во все три списка.
- `cargo build --release -p shortscutter` — 6 мин 26 с на 6 ядрах, `ldd` без ненайденных; `cargo test --workspace --release` —
  все 180 зелёные (после исправления ниже); пример `transcribe` на `media/twitch-1min.wav` — 101 слово за 8.6 с на Vulkan,
  как на Ubuntu; приложение в headless sway (pixman): окно, ffmpeg 9.0.2, `h264_vaapi`/`hevc_vaapi` работают, `av1_vaapi`
  отбракован пробным кодированием, ролик распознан, предложение скачать LLM (скриншот — `/root/work/shots/arch-run.png` на VPS).

**Ошибка, найденная на Arch:** во встроенном `JetBrainsMono-Bold.ttf` (2.304) `usWeightClass` = 558, а не 700. Без
системной копии JetBrains Mono у моноширинного не было начертания 700, и «Bold» рисовался ExtraBold-ом (ближайший вес).
На ПК пользователя тест проходил, потому что там стоит системный JetBrains Mono. Исправление — `fix_bundled_weights` в
`sc-raster::fonts`: у встроенных начертаний вес берётся из PostScript-имени (`…-Bold` → 700), файлы шрифтов не меняются.
Тест `bundled_fonts` теперь проверяет веса самих встроенных файлов (без исправления — падает: `[400, 558, 800]`).

**README** переписан: требования (CPU с AVX2, Vulkan-GPU от 8 ГБ, ffmpeg/libmpv, портал, модели ~8.2 ГБ), установка `.deb`,
сборка из исходников со списками пакетов для Ubuntu/Debian, Arch (проверено) и Fedora (не проверялось — имена пакетов
по памяти, ffmpeg и mpv из RPM Fusion).
