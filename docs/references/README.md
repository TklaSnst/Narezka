## Важное наблюдение

На `hrenn-short-4000.jpg` кнопки интерфейса YouTube справа перекрывают правую часть баннера
(«ССЫЛКА В КОММЕНТАРИЯХ»). Отсюда требование: оверлей безопасных зон Shorts в редакторе.
