## Общие выводы

1. **Момент — это завязка и развязка, без раскачки.** Шортс начинается сразу с ситуации и заканчивается на реакции/панчлайне.
   Длина обычно 15–45 с.
2. **Компоновка меняется по ходу шортса**: сплит ↔ игра на весь экран ↔ лицо крупно. Это главное отличие от шаблонов для
   своих роликов, где компоновка одна на весь шортс.
3. **Субтитры** — тот же стиль, что уже есть (пословно, ключевые цветом), язык — как в речи.
4. **Тексты поверх**: хук-заголовок вверху, ремарки действий («\*swallows…\*»), эмодзи.
5. **Монтаж**: повтор момента, склейка реакции и причины, вырезание пустого.
